# 控制台设计与性能审计（2026-09-16）

初版已经有统一令牌、浅深色、三档导航、原生网页和本机接口，方向成立。主要不足是宽屏信息分组偏弱、交互有遗漏，以及日志在后台仍占用资源。此次保留原生、零依赖、资源内嵌的架构，直接修整同一份控制台。

设计依据是[项目规范](GUIDELINES.md)、[文案规范](CONTENT.md)与 [Material 3 Expressive](https://m3.material.io/blog/building-with-m3-expressive)。沿用项目为中文阅读制定的字阶；这里的动效是轻量 CSS 实现，不声称等同于原生物理弹簧。

## 视觉与交互

| 审计发现 | 改进 |
| --- | --- |
| 总览在宽屏逐块纵向堆叠，大面积留白但主要状态仍在屏外 | 1100px 起按运行、读数、连接、最近日志分成两列；窄屏维持同一阅读顺序 |
| 主色容器与背景过于接近 | 在 `scheme-console` 定义成对的浅深主色容器，强化运行时长与操作层次；卡片采用色调分层 |
| 浅色页面上的深色日志面板套用深红、深黄文本 | 增加日志专用色彩角色，两种主题都保持深底与明亮的语义色；显示级别文字，避免只靠颜色 |
| 芯片 36px、开关 32px，手机点按偏小 | 按钮、筛选与开关实际触控高度统一为 48px；开关轨道仍为 52×32 |
| 搜索焦点不明显、弹窗缺少名称关联 | 补充键盘焦点、跳到内容、换页标题焦点、弹窗名称与描述关联、可键盘滚动的日志区域 |
| 宽屏开关被行点击截获 | 行打开详情仅处理非按钮区域，开关禁用期间防止重复提交，成功后显示确认状态 |
| 慢请求能覆盖后选中的详情 | 详情请求序号与节点有效性共同检查，迟到响应不会改回旧插件 |
| 指令提交与连接开关未正确接入 | 指令统一走表单 submit，点击和回车共用；连接开关只改表单，保存后提交；中文输入法确认不执行指令 |
| 极窄屏搜索与并排详情容易挤压 | 搜索容器限制宽度，并排详情字段单列；长键名必要时折行，保持全部可读 |

## Termux 资源约束

- 没有额外前端框架、远程字体、CDN 或常驻动画。静态资源继续支持 ETag。
- 只在日志页可见时连接 SSE；换页、隐藏标签页与 pagehide 都关闭。返回后由服务端发送最近快照，后台不解析日志。
- 快照与订阅在同一把日志锁内取得；推送也在这把锁内发布，消除“先取历史再订阅”的缺口。消费者落后时重新取快照，不静默跳行。
- 服务端收到首行后合批 50ms，正常批次最多 128 行；浏览器最多每 100ms 更新一次。页面缓冲最多 2000 行，DOM 最多 120 行，屏外行使用 `content-visibility`。降低 DOM 上限是为了减少筛选与恢复时的长任务；完整记录仍在终端日志中。
- 暂停保留 DOM、文字选择与滚动位置，新行只进入缓冲。主动向上翻阅也会暂停；“回到最新”再补画。
- 总览只请求最近 6 行，不再为显示 6 行传输整份缓冲。总览数据打开或手动刷新时获取，不轮询数据库。
- 减少动态效果设置同时关闭骨架、加载与刷新旋转。

## 可重复验证

```sh
cargo test --locked
cargo build --release --locked
node tests/console-backend.cjs
node tests/console.cjs
AYJX_CONSOLE_SHOTS="$TMPDIR/ayjx-console-review" node tests/console.cjs
bash scripts/review-console.sh
```

`console-backend.cjs` 复制 release 可执行文件到临时目录，使用隔离配置、数据库与前台 stdin。验证口令、历史上限、SSE 快照和后续批次、前台响应、配置保存、内嵌资源与优雅退出，不连接 Satori、不发送群消息。

`console.cjs` 使用真实 Chromium/WebDriver 与本地 HTTP 测试数据。验证窄屏导航、宽屏开关、迟到响应、确认框、表单、2400 行突发日志、暂停、筛选、离页断连、隐藏与恢复、320/390/800/1400px、浅深色与减少动态效果。截图与长任务数据只写到指定输出目录。浏览器测试需要 `chromedriver`。

`review-console.sh` 用于查看运行实例的真实页面，现已移除会改变线上 logger 开关的步骤。它只读页面、打开并取消确认框；写操作全部交给隔离测试。

测试能验证行为与限制，不能保证所有 Android 设备在任意负载下都达到固定帧率。实际手机的浏览器、温控与同时进行的出图任务仍会影响响应；测试测得的耗时应连同设备与负载背景解读。

## 本轮验证记录

- 本机 Termux 的 Chromium 回归通过上述页面与操作；2400 行突发、暂停、筛选、换页与恢复这一段，最终两次运行均未记录到 ≥50ms 的长任务。此前 500 行 DOM、逐条消息的同类试验出现过 56–258ms 长任务。这里是该测试场景的对比，不是所有设备的帧率承诺。
- 隔离前台实例保持 SSE 连接时，指令回执约 50ms；空测试库的总览接口中位数约 3.9ms。运行实例的真实总览接口在本轮只读测量中，中位数约 29ms，第一次约 432ms。
- 按最终色彩令牌计算，日志正文对比度 12.95:1、次要信息 8.61:1、警告 10.36:1、错误 9.50:1；主色容器正文浅色 9.65:1、深色 7.37:1。
- 全仓 `cargo fmt --check` 发现原有 `src/http.rs` 测试代码的格式差异；本次修改的 Rust 文件通过独立 `rustfmt --check`，未把无关文件混入变更。
