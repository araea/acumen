# 角色画像

读一个群成员的历史发言，给他出一份**角色画像**，出一张图文报告。指令是 `画像`。

这份东西是发在群里给大家看着玩的：群友拿它互相调侃、哈哈一笑，不当真。所以它敢下判断、敢夸张；同时每一句都留了出处，读者随时能看到这句话是从哪儿来的。

## 四层：观测、档案、戏说、判词

| 层 | 是什么 | 谁产出 | 版式 |
| --- | --- | --- | --- |
| 观测 | **语言指纹**、**活跃节律**、**口头禅**、**群内往来** | 全部由 `collect.rs` 从库里数出来，不经模型 | 事实筹码、两根柱状图、逐字引语、双向条 |
| 档案 | **十个维度**各一句判定，每条带一档把握与一条依据 | 模型读观测与样本得出 | 带把握徽章的十行 |
| 戏说 | **标签墙**与**小传** | 模型，允许夸张 | 短词芯片 + 一段衬线 |
| 判词 | **综述**四到六段，末尾收一句**判词** | 模型，允许隐喻、典故、反问、反语 | 段落与引语交织，末尾一条细线隔出大字 |

两个性质写在报告上。**可核验**：观测每一条都回得到原始记录；档案里标「明说」的那几格、口头禅那几句，都逐字比对过。**有损**：没观测到的部分一句也没有；戏说那一节明写着是玩笑，判词那一句是读法。

四层之外还有一处笔法，落在综述与判词上：那是**亮刀**的地方，见[下面那一节](#亮刀综述与判词)。

## 为什么不再给任何人定 MBTI

上一版给每个人算 MBTI 四轴与九型核心。凭一个人打过的字给他一个四字母的型，是把一次粗糙的归类说得像一次测量——他可能只是在群里抬杠，可能只是那阵子正忙一件不相干的事，而「INTJ」看不出这些。那一层整块拿掉了。

## 为什么现在敢让他下判断

这一版是**娱乐向**的：允许夸张、允许说偏，判断错了也没关系。但判断要有影子——他说过的话、他出现的时间、他聊的事。没有影子的身份不写，因为那样的笑话不好笑：读者一眼就知道是编的。

保住「有影子」这件事的是两条：档案每一格都要给一条依据；标了「明说」的依据与全部口头禅由代码逐字核。**允许夸张的是戏说与判词的写法，不是它们的出处**——比喻、典故、反语都可以用，但底下压着的那件事得是真的。

## 用法

| 指令 | 说明 |
| --- | --- |
| `/画像` | 查看自己的画像 |
| `/角色画像` / `/用户画像` / `/我的画像` / `/人物画像` / `/画像报告` | 同上 |
| `/画像 @某人` | 查看对方的画像 |
| `/画像 <QQ号>` | 按 QQ 号查看 |

关键词之后只允许空白、`@`、一串数字，或者「报告」两个字，其余一律不算指令。日常闲聊里说到「画像」这个词不会触发模型调用。

唯一的例外是消息里带了明确的 `@`：平台会把「@某人的名字」也写进文本段，于是关键词后面常常跟着「黑猫警长」以及他随口的半句话。目标是谁已经写在 `@` 里，这时候不再要求后面只能跟空白与数字。前缀也可以躲在名字后面，`@小黑 /画像` 与 `/画像 @某人` 都认。消息里 `@` 机器人自己不算目标，会退回成查自己。

没有 `算卦`、`起卦` 这类别名。这个插件只做一件事。

## 报告的结构

| 区块 | 内容 |
| --- | --- |
| 一句话定位 | 4—12 字的戏称，加一句六十个字写满的概括——这份东西的脸 |
| 人物档案 | 十个维度各一格：判定、把握徽章、依据。没写出来的格子不占版面 |
| 戏说 | 3—5 枚短标签（每枚配一句为什么）+ 一段小传 |
| 怎么说话 | 一排事实筹码（语言指纹）+ 模型对它们的一段白描 |
| 口头禅 | 他原样说过三遍以上的那几句，逐字照抄 |
| 什么时候来 | 24 小时的柱 + 一周七天的柱 + 一行说明 |
| 群内往来 | 跟谁聊得来：头像、两组计数、一条双向的条、一句读法 |
| 画像综述 | 四到六段，段落与引语交织，引语落在论证里，不贴到文末；末尾一条细线隔出**判词** |
| 页脚 | 观测区间、样本条数、写出几格、模型，一条能立刻照打的下一步，以及那句「不等于本人」 |

## 人物档案：十个维度

十个维度固定，不许模型自创。认不出维度的整条丢掉（`persona.rs` 的 `facet_of`）。

| 维度 | 读的是 |
| --- | --- |
| 性格 TEMPERAMENT | 脾气与待人的方式。说事先给结论还是先铺垫 |
| 兴趣 INTERESTS | 长期在聊什么、钻研什么、反复回到哪个话题 |
| 好恶 TASTES | 明确夸过的、明确嫌弃的 |
| 生计 LIVELIHOOD | 做什么的、在上班还是在读书、手头什么状态 |
| 家庭 FAMILY | 家里人、成长的地方、如今的住处 |
| 年岁 AGE | 年龄段与性别 |
| 学历 EDUCATION | 在读还是毕业了、学什么、学校什么样 |
| 经历 BIOGRAPHY | 他自己讲过的经历、换过的地方、有过的转变 |
| 志向 ASPIRATION | 想做什么、在准备什么、说过的不甘心 |
| 人际 RELATIONSHIP | 现实里的朋友、同事、伴侣，和这些人之间的事 |

一个维度只有一格，模型给多条时留第一条。**判定或依据为空的整条丢掉**——没有依据的话不进报告。提示词要求能写的格子尽量写满、没影子的留空、有影子但拿不准的就猜并标成「待考」。

## 把握三档

每一格必须标一档，档名与意思写在 `persona.rs` 的 `CERTAINTIES` 与 `certainty_note` 里，卡片上的图例与提示词共用同一份说法。

| 档 | 含义 | 版式 |
| --- | --- | --- |
| 明说 STATED | 他本人讲过 | 主色实心徽章；依据按原话处理，加一道主色竖线 |
| 可推 INFERRED | 多条线索指向同一个结论 | 淡主底徽章 |
| 待考 OPEN | 只有一处间接线索，或者是猜的 | 只描一道虚线的徽章 |

**「明说」这一档由代码验，不由模型自称。** 依据必须逐字出自下发的样本，比对按归一化做（去标点与空白、忽略大小写），与引语的判据是同一把尺（`quote_is_from_samples`）。对不上就**降成「可推」**——不清空、不报错。模型可能只是把引号写歪了，那句话仍然有信息；冒认的把握才是要修的那个东西。

依据写成「他说『…』」这种形状时，收口会把引号里那句取出来做比对，并通过它当依据（`evidence_as_quote`），版面上那句话因此是干净的。

「待考」这一档是留给猜的：这一版要的就是敢猜，也敢承认自己是在猜。

## 可以玩的，与不可以玩的

提示词里写着这条界线（`persona.rs` 的 SYSTEM_PROMPT）。

可以玩：他说过的职业、收入的样子、年纪、学历、感情、作息、口头禅，都可以拿来开玩笑。把一个天天半夜修电脑的人说成「赛博流浪汉」，只要他的记录里有影子，就成立。

不可以玩的两样：**外貌**（胖瘦、美丑）与**健康**（病、身体缺陷）。这两样不好笑，只伤人。另有一类不写：能定位到具体个人的信息——真实姓名、门牌、单位全名、电话。

还有一个准星，四种写法（档案的判定、戏说的标签、综述的段落、判词）都归它管：**靶子是他的做法与处境，不是他这个人的价值。** 说得出一个人把日子过成了排班表，说不得他这人不行。这一份会发在群里，他自己也会看到——这是这条界线的全部理由。

## 亮刀：综述与判词

档案那一节给证据，戏说那一节逗笑，综述与判词这一节是让人**安静一下**的：把行为背后那个东西说出来，读者「哦」一声，然后有点不舒服，因为那说的也是他自己。

提示词放开了五种写法：**隐喻与借代**、**典故与成语**、**反问**、**讽刺与反语**、**说穿机制**（不只说他做了什么，说为什么他只能这么做——这样活换到了什么，又付了什么）。含沙射影只许影射「现象」，不许暗指群里其他具体的人，也不许影射现实里的第三者。

**放开的是写法，不是出处。** 每一句判断底下仍然要压着事实；比喻是把事实照亮，不是拿来替事实。空对仗、排比、金句「说了等于没说的」，照旧删。下面这几条也仍然在：

- 不说教（「希望他能……」「其实他需要的是……」）——写的人不是他的长辈；
- 不写空洞的收尾（「而这，就是他的故事。」）；
- 不用评价词与模糊限定；
- 同一个数字不报两遍。

准星只有一条：**靶子是他的做法与处境，不是他这个人的价值。** 这一份会发在群里，他自己也会看到。可以说一个人把日子过成了排班表，不可以暗示他这人不行；可以说「舍不得关灯」，不可以说他可怜。

**判词**是独立的字段（`closing`，30—60 字），排在综述末尾，版面上用大号衬线、上面压一条主色渐变的细线。它与开头那句「一句话定位」分工不同：开头那句要**准**，给读者一个抓手；末尾这句要**狠**，说出他这样活着换到了什么、付了什么。提示词里另写着「判词必须是整份里最锋利的那一句，不是前文的总结——把前文总结一遍等于没写」。前几份用过的判词会随排除表下发，**不许套同一个句式**——十来份判词都写成「他不是 A，是 B」，再好的句子也成了模板。

判词**只有模型给得出**。模型没接时它是空的，不拿一句观测直出的话冒充——那正好砸了这一节的招牌。

## 称号、一句话与判词：不撞车

十来个人拿到十来个「技术宅 / 夜猫子」，这份东西就不好玩了。所以：

- **称号**要求是名词性的短标签，不要「……的人」句式，不要换谁都能套的通用词；提示词里举了例子。
- 每一项发出去的画像，它的**称号、一句话与判词会留在进程状态里**（最近 8 条），下一份画像的提示词里带上这份排除表：称号明写「不许与它们相同或只差一两个字」，判词明写「不许套它们用过的句式」。只在真发出去之后才记——群里没人看见的那份不该占掉别人的说法。
- **一句话**要求里面至少有一处只属于他的具体东西：一个数字、一个时间，或者一件他说过的事。

这一手是这份东西最实际的「个性化」来源：模型看不见别人手里的画像，不给它排除表，它就只会给出同一批模板词；短标签尤其容易撞，判词则容易套成同一个句式。

## 一句话不截断

卡片上留一个省略号就等于丢一句话，所以字数预算是照「不截断」定的：一句话 60 字、判定 40 字、依据 70 字、白描 140 字、小传 140 字、判词 60 字，每一档都留够版面（判词按三行给），超过才截。版面上这些字段都按整段排、允许换行。

## 戏说

`labels` 是 3—5 枚短标签（每枚 ≤10 字）配一句为什么（≤34 字），`sketch` 是一段 ≤140 字的玩笑话。版面上它们跟档案分开排，节头上明写「这一节是拿来玩的：允许夸张，也允许说偏」。

标签不核——那一节本来就是用来笑的。核的是别处：档案的依据、口头禅、引语。

## 口头禅

`collect.rs` 的 `top_phrases` 先把**原样重复过三遍以上的短句**数出来（长度卡在 2—14 字，太短的「6」人人都发、太长的是刷屏），作为候选下发。模型从候选或样本里挑 2—4 句，收口时逐字核：要么逐字出现在样本里，要么正是候选里的那条重复发言（`phrase_is_from_material`）。核不掉的一条都不留。

这一节的底气全在这儿：卡片上印的那几句，一定是他真说过的原话。候选不够就少印几句，一条都没有就整节不出现。**模型没接时这一节照旧成立**——候选本来就是从记录里数出来的。

## 怎么说话

这张表问的是**这个人是怎么说话的**，全篇唯一算得出来的东西之一。分母统一用**可读发言**（`length > 0` 且去掉纯占位标记后仍有字的那些条），空消息、纯图片纯表情不进这一层。字段都写在 `collect.rs` 的 `Style` 里：

| 字段 | 读什么 |
| --- | --- |
| 提问/感叹/省略率 | 以 ？?、！! 收尾，或含省略号的消息占比 |
| 笑声/语气词率 | 含「哈哈 / hh / 233 / 笑死」与「吧呢哦啊嘛啦诶呀」的占比 |
| 自称/对称呼密度 | 每百字「我俺咱」「你您」出现次数——说给自己听还是对着人说 |
| 长度起伏 | 消息长度变异系数，匀称还是时短时长 |
| 长短占比 | 长消息（≥40 字）与短消息（≤5 字）各占多少 |
| 爆发指数 | 发言间隔的 (σ−μ)/(σ+μ)：-1 极匀、0 随机、接近 +1 一阵一阵 |
| 相邻重复 | 与上一条内容相同的占比——口头禅、复读机倾向 |

这些数一路喂给模型的提示词，也是卡片上那一排筹码。筹码下面那段白描是模型的读法，模型不接时这一节只剩筹码。

## 什么时候来

24 小时的柱，加一周七天的柱。两根柱子都不用颜色独自承担信息：峰值那根既上主色、也在下面那行字里点名，0—6 时那一段既换了槽的底色、也在说明里写了占比。一根柱都没有的格子是空的，不画一条最小高度的假柱。

文字版里这一节的回退是**把 24 个与 7 个数一个不落地印出来**（`0—23 时依次：…`），图里有的信息一条不少。

## 群内往来

这一节答的是「他跟谁聊得来」，两个口径都按方向分开数：

| 口径 | 怎么算 | 算事实还是可推 |
| --- | --- | --- |
| 点名 | `content_rich` 里的 `[@QQ]`，同一条里 @ 两次只算一次 | 事实 |
| 接话 | 同一群里紧跟在对方之后的那一条，两分钟以内、中间没有第三个人 | 可推 |

**接话不等于回复**：记录里存不下回复的对象（平台的 reply 段只有一个消息号），所以这一项按可推读，卡片上也是这么写的。

往来量 = 点名双向 + 接话双向，按它排序，最多印 `partners` 个。落选的人一条都不印，不是「往来为零」——只是没进这一页。

每条往来四行：头像与名字、点名、方向条、接话，最后是模型写的那一句。**方向条只画点名**——左边是他叫对方，右边是对方叫他；接话不进这条，因为一来一回本来就是对半的，画进去只会把「他更常找谁」冲淡成一个接近平手的数。谁更主动由代码判（`Tie::initiative`，差不到三成半的说「两边差不多」；一次点名都没有时说「只看接话」，条也不画），模型只写聊什么、什么调子。

**头像**按 QQ 号从 `q.qlogo.cn` 取，尺寸 `spec=140`（卡片上那一枚只有 34 CSS 像素，取大图只是白撑 HTML），六个人并起来取，取不到的退回名字首字。

圆框这一处有个坑：`.tie-face` 只给 `border-radius` 不剪裁，140 像素的原图会照自身尺寸撑开，压掉名字和后面的版面。所以框上要 `overflow:hidden`，图要 `width/height:100%` 加 `object-fit:cover`。布局审计（`tests/cards.cjs`）取样张上的元素溢出，本来该抓到它——但样张里的往来头像当时是空的，审计等于空跑。现在 `portrait-light.html` 那份样张**带一张 40×40 的假头像**（比 34 像素的框大，才复现得出溢出），这条才真正钉住。

**模型只许给名单上的人写话**：收口时按 `id` 对，名单外的条目一律丢掉（`sanitize` 里的 `known`）。往来对象是数出来的，不是模型想出来的。

那一句里不许出现孤零零的「他」：画像对象写「他本人」，对方写「对方」。数字那行里的「他」指的是对方，模型那句里的「他」若指画像对象，同一块里两个「他」就是两个人。

## 那句「正在生成」会被收回去

生成一份画像要跑一分钟上下，中间发一句「⏳ 正在读……的发言记录，整理画像…」是必要的——不然用户以为消息丢了。成品发出来之后它就成了噪声，所以用 `message.delete` 把它收走。中途就收场的那几条路（没有记录、查库出错、模型接口没配好）也一样收：群里只留一条说得清的。

**超过撤回窗口就不去试。** QQ 只给两分钟，超了必然失败；而实现端的出站闸门会把连续的撤回失败算成故障（连撤三条就把整台机器人的发消息能力关上两分钟，见 satori-qq 的 OutboundGuard）。所以 `retract` 先看表：`RETRACT_WINDOW`（100 秒）以内才动手，过了就让它留在群里，日志记一行。一条过期的预告，比机器人失声两分钟轻得多。

收不掉不算失败：日志留一行，群里一个字都不说。

## 报告是怎么来的

分成四步。

1. **采集**。只读 `message_records`，范围是该用户在群里的发言（`group_id != 0`），并排除 `role = 'self'`。本机机器人与号主共用同一个 QQ 号，记录靠 `role` 区分人和机，不排除就会把机器人自己说的话算到号主头上。统计发言总数、活跃天数、24 小时与星期分布、常在的群、消息类型构成与高频词；再扫一遍可读发言，算出语言指纹与口头禅候选。发言样本按时间等距抽取，并保证最长的几条入选。往来另扫一遍「他常住的群」里所有人的记录，按时间取最近的 40000 条（`TIE_SCAN_MAX`）——别人的发言也要读，他接住了谁的话、谁 @ 了他，两样都落在别人的记录里。
2. **分析**。观测四块、口头禅候选、往来账、最近用过的称号、一句话与判词，连同样本交给模型，要求返回一个固定字段的 JSON。这是唯一花钱的一步。
3. **收口**。字数、维度、把握、依据、口头禅、引语、往来名单、判词，逐条核。
4. **出图**。HTML 模板截图，版心 720 CSS 像素。日读与夜读两套纸色主题，按北京时间 07:00—18:59 自动切换。显示级的文字（一句话、档案的判定与依据、语言读法、往来读法、小传、综述、引语、口头禅、判词）用衬线，其余用无衬线。报告开头的头像与往来对象的头像都转成 data URL 内嵌进 HTML。出图失败时退回一份文字版。

### 模型没接上时

**报告仍然出**。观测四节（怎么说话、口头禅、什么时候来、群内往来）一条都不少——它们本来就不经模型；档案十格与戏说整块空着，版面上照实说「这次十格都没写出东西」，一句话挂一枚「模型未接，档案由观测直出」。

不用伪精度去补十格没有依据的判定：没读过语义就编不出诚心的档案，宁可空着。判词同理——它是读出来的，不是数出来的，没有模型就没有判词。

每一次生成的 HTML 会写到 `data/portrait/`，保留最近 40 份，可以用来核对版式。

## 数据去向

报告本身不发原始记录，但下面这些内容会发给 `model` 指向的模型接口：

- 统计数字与高频词；
- 语言指纹的各项比例；
- 口头禅候选（他原样重复过的短句）与候选的重复次数；
- 群内往来的计数（对方的名字与 QQ 号）与他 @ 对方时说过的那几条原话（每人至多 2 条，每条截断到 60 字）；
- 最多 `max_samples` 条发言样本，每条截断到 90 字，总量不超过 9000 字；
- **最近 8 份画像的称号、一句话与判词**（只为让这一份不跟前几份撞车）；
- 对象的群名片与 QQ 号。

接口地址由 `model` 的供应商前缀决定，见 `[oai.providers]`。提示词明确要求不写外貌与健康，不写能定位到具体个人的信息，也不许暗指群里其他具体的人。

出图之前还会向 `q.qlogo.cn` 请求一次对象与往来对象的头像，只取图，不上传任何内容。

报告页脚写着「画像是对行为的抽象，有损：只含他在群里说过的部分，不等于本人。档案每一格都标了把握，标「明说」的依据是他本人的原话；口头禅那几句是原样照抄的；戏说与判词是读法，不是事实。仅供参考，不作凭据。」

## 配置

| 键 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 插件开关 |
| `model` | `deepseek/deepseek-flash` | 分析用的模型，写 `供应商/模型` |
| `thinking` | `high` | 思考强度 `off` / `minimal` / `low` / `medium` / `high` / `xhigh`；留空交给接口默认 |
| `days` | `0` | 只统计最近多少天；0 表示全部留存记录 |
| `max_samples` | `120` | 交给模型的样本条数 |
| `max_scan` | `8000` | 一次最多读多少条本人记录 |
| `partners` | `6` | 报告里最多摆几个往来对象；0 表示不算这一段 |
| `theme` | `auto` | `auto` / `light` / `dark` |
| `image_enabled` | `true` | 是否出卡片图；关掉或渲染失败时退回一份等价的文字版 |
| `image_scale` | `3.0` | 出图倍率，1—4 |
| `cooldown_seconds` | `180` | 同一个目标两次生成之间的最短间隔；这期间再问重发上一次的结果 |
| `channel` | 空 | 群名单，语义同 `[stats.channel]`；**两边都留空就是对所有群生效**，不需要单独开群 |

思考强度默认 `high`：十格、戏说与综述要先读完一百多条样本再落笔，调低会让结论只停在「话多话少、白天黑夜」那一层。

注意 `days`、`max_samples` 与 `partners` 会改变下发的素材，也就改变了这份画像。

## 频次限制

同一个目标同时只允许一次生成。`cooldown_seconds` 之内再问一次，不重新生成，而是把上一次那张卡片（出图失败时是那段文字）原样再发一遍。冷却期里同一批素材算出来的还是同一份，重复生成只会多付一次模型与出图的钱。缓存只留最近问过的那几个人，被挤掉、或者上一次压根没发出东西时，退回一句「刚画过，N 秒后再来」。两道闸只拦发指令的人，不影响其它功能。

## 端到端验证

```sh
cargo test --release portrait_live -- --ignored --nocapture
```

它读 `config.toml` 与 `data/bot.db`，跑真模型、出真图，打印往来账、十格档案、戏说、口头禅、收口后的综述与判词，并把出图写到临时目录。目标默认取记录最多的人，也可以用 `PORTRAIT_LIVE_USER=<QQ号>` 指定。

只想看版式、不联网（把日读、夜读与降级三份 HTML 写出来）：

```sh
PORTRAIT_CARD_DUMP=$PREFIX/tmp/portrait cargo test portrait::card::tests::dump -- --ignored
```

### 出图预算

画像卡是几张卡里最长的一张，而 `render::web` 有一道「宽度 × 高度 × 倍率² ≤ 6400 万」的像素护栏，超了会静默退回文字版。改完版式拿探针量一次：

```sh
cargo test --release portrait_card_budget -- --ignored --nocapture
```

它取最近归档的那份真卡片（`target/release/data/portrait/`，跑过 `portrait_live` 也会留一份），按 1/2/3/4 倍各截一次并打印像素数。2026-09-21 实测：真卡片 6419 CSS 像素高，线上那档倍率 3 是 2160×19257 ≈ 4160 万像素，在护栏内，离上限还有三成余量；倍率 4 会超。

## 界面取自哪里

色值、字号、圆角、间距一律取 `res/cards/m3e.css` 的令牌，版式层不写数值。这套令牌属于个人设计系统，规范本体在 `github.com/araea/design-system`，本仓库不放副本。
