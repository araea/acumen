# 用户画像

读一个群成员的历史发言，按**活跃、内容、交互、表达**四个维度打出标签，写一段综述，出一张图文报告。指令是 `画像`。

画像在这里的意思是按数据领域的定义来的：**从用户的行为数据里抽象出来的一个标签化模型**。报告上写着它的两个性质。可核验：每一条标签都能回到他做过的事上。有损：没观测到的部分一句话也没有。

## 用法

| 指令 | 说明 |
| --- | --- |
| `/画像` | 查看自己的画像 |
| `/用户画像` / `/我的画像` / `/画像报告` | 同上 |
| `/画像 @某人` | 查看对方的画像 |
| `/画像 <QQ号>` | 按 QQ 号查看 |

关键词之后只允许空白、`@`、一串数字，或者「报告」两个字，其余一律不算指令。日常闲聊里说到「画像」这个词不会触发模型调用。

唯一的例外是消息里带了明确的 `@`：平台会把「@某人的名字」也写进文本段，于是关键词后面常常跟着「黑猫警长」以及他随口的半句话。目标是谁已经写在 `@` 里，这时候不再要求后面只能跟空白与数字。前缀也可以躲在名字后面，`@小黑 /画像` 与 `/画像 @小黑` 都认。消息里 `@` 机器人自己不算目标，会退回成查自己。

没有 `算卦`、`起卦` 这类别名。这个插件只做一件事。

## 报告的结构

| 区块 | 内容 |
| --- | --- |
| 读数 | 发言数、活跃天数、跨度、平均字数、最密的钟点、样本充分性 |
| 综合标签 | 2—7 字的称谓，加一句话概括 |
| 标签体系 | 四个维度下的标签，每条带抽象层级与证据 |
| 画像综述 | 四到六段白描，段落与引语交织，引语落在论证里，不贴到文末 |
| 页脚 | 观测区间、样本条数、模型，以及那句「不等于本人」 |

没有分点罗列，没有刻度条，没有卦象。

## 标签体系

四个维度固定，不许模型自创。某个维度没有标签就整块不印。

| 维度 | 读的是 |
| --- | --- |
| 活跃 ACTIVITY | 什么时候出现，去得勤不勤，密度如何 |
| 内容 CONTENT | 说什么，反复说什么，哪些话题从来不碰 |
| 交互 INTERACTION | 跟谁说话，主动发起还是接话，他说的时候别人接不接 |
| 表达 EXPRESSION | 怎么说：长短、句读、用不用图片表情语音 |

每条标签还要标出它的抽象层级，只有三层，从事实到推断：

| 层级 | 含义 | 版式 |
| --- | --- | --- |
| 事实 OBSERVED | 观测即得，不做推断。条数、时刻、占比、媒介构成、原话 | 浅底徽章 |
| 统计 DERIVED | 把观测按一个阈值归成一类，阈值要一起写出来 | 描边徽章 |
| 推断 INFERRED | 从样本的意思里读出来的，一条必须有一条原话或一组数字顶着 | 实心徽章 |

提示词对标签的条数有硬性规定：每个维度 2 到 4 条，整个画像 8 到 16 条，**推断标签不超过总数的一半**。认不出维度的标签收口时直接丢掉（`persona.rs` 的 `dimension_of`）。一个维度最多印四条，四个维度都得有位置。层级认不出来的一律按**推断**处理，没标「观测即得」的不按事实读。

### 样本充分性

读数那一行最末一格给的是这份画像能信到什么程度，阈值写在 `collect.rs` 的 `Sufficiency` 里：

| 判定 | 条件 |
| --- | --- |
| 充分 | 发言 200 条以上，且活跃 14 天以上 |
| 一般 | 发言 50 条以上，且活跃 5 天以上 |
| 有限 | 其余 |

## 提示词

`persona.rs` 的 `SYSTEM_PROMPT` 开头先把画像是什么说清楚（标签化模型、可核验、有损），再定三层标签怎么分，最后定综述的笔法：白描，一句话说一件事写成完整陈述句。每一句判断后面要有他说过的话、做过的动作、数字或时间撑着。不用比喻、对仗、金句与格言体，不用评价词与模糊限定。段末说完事就停，不加总结性判断。数字一段里至多两三处。另外明确要求不写外貌、性别、年龄、地域、收入、健康与政治立场，也不臆断具体职业、住处与私人关系。

模型返回一个固定字段的 JSON。**引语必须逐字出自样本**，收口时按归一化（去掉标点与空白）比对，对不上的丢掉，报告里不出现编出来的「他说过」。

## 报告的来源

分成四步。

1. 采集。只读 `message_records`，范围是该用户在群里的发言（`group_id != 0`），并排除 `role = 'self'`。本机机器人与号主共用同一个 QQ 号，记录靠 `role` 区分人和机，不排除就会把机器人自己说的话算到号主头上。统计发言总数、活跃天数、24 小时与星期分布、常在的群、消息类型构成与高频词。发言样本按时间等距抽取，并保证最长的几条入选。
2. 分析。统计量与样本交给模型，要求返回一个固定字段的 JSON。这是唯一花钱的一步。模型不接时报告仍然成立，只是少了推断层与那段综述。
3. 收口。字数、条数、维度、层级、引语逐条核对。
4. 出图。HTML 模板截图，版心 720 CSS 像素，正文 19.5—20.5px、行高 1.9—2.0。日读与夜读两套纸色主题，按北京时间 07:00—18:59 自动切换。显示级的文字（综合标签、维度名、综述、引语）用衬线，其余用无衬线。报告开头的头像按 QQ 号从 QQ 公开头像 CDN（`q.qlogo.cn`）取回，转成 data URL 内嵌进 HTML。取不到时用名字首字代替。出图失败时退回一份文字版。

**模型调用失败、超时或 JSON 解析失败时仍然出报告**：标签退回统计直出，只有事实与统计两层，综述只写一句事实，卡片上标「模型未接，标签由统计直出」。

每一次生成的 HTML 会写到 `data/portrait/`，保留最近 40 份，可以用来核对版式。

## 数据去向

报告本身不发原始记录，但下面这些内容会发给 `model` 指向的模型接口：

- 统计数字与高频词；
- 最多 `max_samples` 条发言样本，每条截断到 90 字，总量不超过 9000 字；
- 对象的群名片与 QQ 号。

接口地址由 `model` 的供应商前缀决定，见 `[oai.providers]`。提示词明确要求模型不写外貌、性别、年龄、地域、收入、健康与政治立场，也不臆断具体职业、住处与私人关系。

出图之前还会向 `q.qlogo.cn` 请求一次该 QQ 号的头像，只取图，不上传任何内容。

报告页脚写着「画像是对行为的抽象，有损：只含他在群里说过的部分，不等于本人。仅供娱乐，不作凭据。」

## 配置

| 键 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 插件开关 |
| `model` | `deepseek/deepseek-flash` | 分析用的模型，写 `供应商/模型` |
| `thinking` | `high` | 思考强度 `off` / `minimal` / `low` / `medium` / `high` / `xhigh`；留空交给接口默认 |
| `days` | `0` | 只统计最近多少天；0 表示全部留存记录 |
| `max_samples` | `120` | 交给模型的样本条数 |
| `max_scan` | `8000` | 一次最多读多少条原始记录 |
| `theme` | `auto` | `auto` / `light` / `dark` |
| `image_enabled` | `true` | 是否出卡片图；关掉或渲染失败时退回一份等价的文字版 |
| `image_scale` | `3.0` | 出图倍率，1—4 |
| `cooldown_seconds` | `180` | 同一个目标两次生成之间的最短间隔；这期间再问重发上一次的结果 |
| `channel` | 空 | 群名单，语义同 `[stats.channel]`；**两边都留空就是对所有群生效**，不需要单独开群 |

思考强度默认 `high`：标签与综述要先读完一百多条样本再落笔，调低会让结论只停在「话多话少、白天黑夜」这一层。

注意 `days` 与 `max_samples` 会改变下发的素材，也就改变了这份画像。

## 频次限制

同一个目标同时只允许一次生成。`cooldown_seconds` 之内再问一次，不重新生成，而是把上一次那张卡片（出图失败时是那段文字）原样再发一遍。冷却期里同一批素材算出来的还是同一份，重复生成只会多付一次模型与出图的钱。缓存只留最近问过的那几个人，被挤掉、或者上一次压根没发出东西时，退回一句「刚画过，N 秒后再来」。两道闸只拦发指令的人，不影响其它功能。

## 端到端验证

```sh
cargo test --release portrait_live -- --ignored --nocapture
```

它读 `config.toml` 与 `data/bot.db`，跑真模型、出真图，打印标签表与收口后的画像，并把出图写到临时目录。目标默认取记录最多的人，也可以用 `PORTRAIT_LIVE_USER=<QQ号>` 指定。

只想看版式、不联网（把日读、夜读与降级三份 HTML 写出来）：

```sh
PORTRAIT_CARD_DUMP=$PREFIX/tmp/portrait cargo test portrait::card::tests::dump -- --ignored
```
