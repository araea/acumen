# 角色画像

读一个群成员的历史发言，给他出一份**角色档案**，出一张图文报告。指令是 `画像`。

## 两层，从硬到软

| 层 | 是什么 | 谁产出 | 版式 |
| --- | --- | --- | --- |
| 观测 | **语言指纹**、**活跃节律**、**群内往来** | 全部由 `collect.rs` 从库里数出来，不经模型 | 一排事实筹码、两张柱状图、一条条双向条 |
| 档案 | **九个维度**各一句判定，每条带一档把握与一条依据 | 模型读观测与样本得出 | 带把握徽章的九格 |

两个性质写在报告上。**可核验**：观测每一条都回得到原始记录，档案里标「明说」的那几格，依据是他本人的原话。**有损**：没观测到的部分一句话也没有。

## 为什么不再给任何人定 MBTI

上一版给每个人算 MBTI 四轴与九型核心。凭一个人打过的字给他一个四字母的型，是把一次粗糙的归类说得像一次测量：他可能只是在群里抬杠，可能只是那阵子在忙一件不相干的事，而「INTJ」这个标签看不出这些。

这一版把那一层整块拿掉，换成九格档案。判断一个人是什么样，看他亲口说过什么，比看他在四个轴上的位置诚实得多——**每一格都要指得出出处，读的人也就知道哪一句能信到什么程度**。

## 用法

| 指令 | 说明 |
| --- | --- |
| `/画像` | 查看自己的画像 |
| `/角色画像` / `/用户画像` / `/我的画像` / `/人物画像` / `/画像报告` | 同上 |
| `/画像 @某人` | 查看对方的画像 |
| `/画像 <QQ号>` | 按 QQ 号查看 |

关键词之后只允许空白、`@`、一串数字，或者「报告」两个字，其余一律不算指令。日常闲聊里说到「画像」这个词不会触发模型调用。

唯一的例外是消息里带了明确的 `@`：平台会把「@某人的名字」也写进文本段，于是关键词后面常常跟着「黑猫警长」以及他随口的半句话。目标是谁已经写在 `@` 里，这时候不再要求后面只能跟空白与数字。前缀也可以躲在名字后面，`@小黑 /画像` 与 `/画像 @小黑` 都认。消息里 `@` 机器人自己不算目标，会退回成查自己。

没有 `算卦`、`起卦` 这类别名。这个插件只做一件事。

## 报告的结构

| 区块 | 内容 |
| --- | --- |
| 综合速写 | 4—9 字的称谓，加一句话概括——这份东西的脸 |
| 人物档案 | 九个维度各一格：判定、把握徽章、依据。没写出来的格子不占版面 |
| 怎么说话 | 一排事实筹码（语言指纹）+ 模型对它们的一段白描 |
| 什么时候来 | 24 小时的柱 + 一周七天的柱 + 一行说明 |
| 群内往来 | 跟谁聊得来：两组计数、一条双向的条、一句读法 |
| 画像综述 | 四到六段白描，段落与引语交织，引语落在论证里，不贴到文末 |
| 页脚 | 观测区间、样本条数、写出几格、模型，一条能立刻照打的下一步，以及那句「不等于本人」 |

没有分点罗列，没有刻度条，没有卦象，也没有「群聊钩子」——把一个人的职业、家里人、手头宽不宽裕拿去做群里的讨论话题，是上一版留下的东西，这一版整块删了。

## 人物档案：九个维度

九个维度固定，不许模型自创。认不出维度的整条丢掉（`persona.rs` 的 `facet_of`）。

| 维度 | 读的是 |
| --- | --- |
| 性格 TEMPERAMENT | 脾气与待人的方式。说事先给结论还是先铺垫 |
| 兴趣 INTERESTS | 长期在聊什么、钻研什么、反复回到哪个话题 |
| 好恶 TASTES | 明确夸过的、明确嫌弃的 |
| 生计 LIVELIHOOD | 做什么的、在上班还是在读书、手头宽不宽裕 |
| 家庭 FAMILY | 家里人、成长的地方、如今的住处 |
| 年岁 AGE | 年龄段与性别 |
| 经历 BIOGRAPHY | 他自己讲过的经历、换过的地方、有过的转变 |
| 志向 ASPIRATION | 想做什么、在准备什么、说过的不甘心 |
| 人际 RELATIONSHIP | 现实里的朋友、同事、伴侣，和这些人之间的事 |

一个维度只有一格，模型给多条时留第一条。**判定或依据为空的整条丢掉**——没有依据的话不进报告。

这一节有几条硬边：

- 生计这一格不给他排档、不评价他有没有钱，只写他说过的。
- 年岁写年龄段（十来岁、二十出头、三十上下），不写具体岁数。性别只在有依据时写。
- 不写能定位到具体个人的东西：真实姓名、门牌、单位全名、电话。
- 不写外貌、健康状况、政治立场、性取向。
- 他没有说过的，一个字都不许补。

## 把握三档

每一格必须标一档，档名与意思写在 `persona.rs` 的 `CERTAINTIES` 与 `certainty_note` 里，卡片上的图例与提示词共用同一份说法。

| 档 | 含义 | 版式 |
| --- | --- | --- |
| 明说 STATED | 他本人讲过 | 主色实心徽章；依据按原话处理，加一道主色竖线 |
| 可推 INFERRED | 多条线索指向同一个结论 | 淡主底徽章 |
| 待考 OPEN | 只有一处间接线索 | 只描一道虚线的徽章 |

**「明说」这一档由代码验，不由模型自称。** 依据必须逐字出自下发的样本，比对按归一化做（去标点与空白、忽略大小写），与引语的判据是同一把尺（`quote_is_from_samples`）。对不上就**降成「可推」**——不清空、不报错。模型可能只是把引号写歪了，那句话仍然有信息；冒认的把握才是要修的那个东西。

依据写成「他说『…』」这种形状时，收口会把引号里那句取出来做比对，并通过它当依据（`evidence_as_quote`），版面上那句话因此是干净的。

拿不准就写可推或待考。提示词里写明「宁降不升」。

## 怎么说话

这张表问的是**这个人是怎么说话的**，全篇唯一算得出来的东西之一。分母统一用**可读发言**（`length > 0` 且去掉纯占位标记后仍有字的那些条），空消息、纯图片纯表情不进这一层。字段都写在 `collect.rs` 的 `Style` 里：

| 字段 | 读什么 |
| --- | --- |
| 提问/感叹/省略率 | 以 ？?、！! 收尾，或含省略号的消息占比 |
| 笑声/语气词率 | 含「哈哈 / hh / 233 / 笑死」与「吧呢哦啊嘛啦诶呀」的占比 |
| 自称/对称呼密度 | 每百字「我俺咱」「你您」出现次数——说给自己听还是对着人说 |
| 长度起伏 | 消息长度变异系数，匀称还是时短时长 |
| 长短占比 | 长消息（≥40 字）与短消息（≤5 字）各占多少 |
| 爆发指数 | 发言间隔的 (σ−μ)/(σ+μ)：-1 极匀、0 随机、接近 +1 一阵一阵 |
| 相邻重复 | 与上一条内容相同的占比——口头禅、复读机倾向 |

这些数一路喂给模型的提示词，也是卡片上那一排筹码。筹码下面那段白描是模型的读法，模型不接时这一节只剩筹码。

## 什么时候来

24 小时的柱，加一周七天的柱。两根柱子都不用颜色独自承担信息：峰值那根既上主色、也在下面那行字里点名，0—6 时那一段既换了槽的底色、也在说明里写了占比。一根柱都没有的格子是空的，不画一条最小高度的假柱。

文字版里这一节的回退是**把 24 个与 7 个数一个不落地印出来**（`0—23 时依次：…`），图里有的信息一条不少。

## 群内往来

这一节答的是「他跟谁聊得来」，两个口径都按方向分开数：

| 口径 | 怎么算 | 算事实还是可推 |
| --- | --- | --- |
| 点名 | `content_rich` 里的 `[@QQ]`，同一条里 @ 两次只算一次 | 事实 |
| 接话 | 同一群里紧跟在对方之后的那一条，两分钟以内、中间没有第三个人 | 可推 |

**接话不等于回复**：记录里存不下回复的对象（平台的 reply 段只有一个消息号），所以这一项按可推读，卡片上也是这么写的。

往来量 = 点名双向 + 接话双向，按它排序，最多印 `partners` 个。落选的人一条都不印，不是「往来为零」——只是没进这一页。

每条往来四行：名字、点名、方向条、接话，最后是模型写的那一句。**方向条只画点名**——左边是他叫对方，右边是对方叫他；接话不进这条，因为一来一回本来就是对半的，画进去只会把「他更常找谁」冲淡成一个接近平手的数。谁更主动由代码判（`Tie::initiative`，差不到三成半的说「两边差不多」；一次点名都没有时说「只看接话」，条也不画），模型只写聊什么、什么调子。

**模型只许给名单上的人写话**：收口时按 `id` 对，名单外的条目一律丢掉（`sanitize` 里的 `known`）。往来对象是数出来的，不是模型想出来的。

那一句里不许出现孤零零的「他」：画像对象写「他本人」，对方写「对方」。数字那行里的「他」指的是对方，模型那句里的「他」若指画像对象，同一块里两个「他」就是两个人。

## 报告是怎么来的

分成四步。

1. **采集**。只读 `message_records`，范围是该用户在群里的发言（`group_id != 0`），并排除 `role = 'self'`。本机机器人与号主共用同一个 QQ 号，记录靠 `role` 区分人和机，不排除就会把机器人自己说的话算到号主头上。统计发言总数、活跃天数、24 小时与星期分布、常在的群、消息类型构成与高频词；再扫一遍可读发言，算出语言指纹。发言样本按时间等距抽取，并保证最长的几条入选。往来另扫一遍「他常住的群」里所有人的记录，按时间取最近的 40000 条（`TIE_SCAN_MAX`）——别人的发言也要读，他接住了谁的话、谁 @ 了他，两样都落在别人的记录里。
2. **分析**。观测三块与样本交给模型，要求返回一个固定字段的 JSON。这是唯一花钱的一步。
3. **收口**。字数、维度、把握、依据、引语、往来名单，逐条核。
4. **出图**。HTML 模板截图，版心 720 CSS 像素。日读与夜读两套纸色主题，按北京时间 07:00—18:59 自动切换。显示级的文字（综合速写、档案的判定与依据、语言读法、往来读法、综述、引语）用衬线，其余用无衬线。报告开头的头像按 QQ 号从 QQ 公开头像 CDN（`q.qlogo.cn`）取回，转成 data URL 内嵌进 HTML。取不到时用名字首字代替。出图失败时退回一份文字版。

### 模型没接上时

**报告仍然出**。观测三节（怎么说话、什么时候来、群内往来）一条都不少——它们本来就不经模型；档案九格整块空着，版面上照实说「这次九格都没写出东西」，综合速写挂一枚「模型未接，档案由观测直出」。

不用伪精度去补九格没有依据的判定：没读过语义就编不出诚心的档案，宁可空着。

每一次生成的 HTML 会写到 `data/portrait/`，保留最近 40 份，可以用来核对版式。

## 数据去向

报告本身不发原始记录，但下面这些内容会发给 `model` 指向的模型接口：

- 统计数字与高频词；
- 语言指纹的各项比例；
- 群内往来的计数（对方的名字与 QQ 号）与他 @ 对方时说过的那几条原话（每人至多 2 条，每条截断到 60 字）；
- 最多 `max_samples` 条发言样本，每条截断到 90 字，总量不超过 9000 字；
- 对象的群名片与 QQ 号。

接口地址由 `model` 的供应商前缀决定，见 `[oai.providers]`。提示词明确要求模型不写外貌、健康状况、政治立场与性取向，不写能定位到具体个人的信息，没观测到的一个字都不补。

出图之前还会向 `q.qlogo.cn` 请求一次该 QQ 号的头像，只取图，不上传任何内容。

报告页脚写着「画像是对行为的抽象，有损：只含他在群里说过的部分，不等于本人。档案每一格都标了把握，标「明说」的那几格，依据是他本人的原话。仅供参考，不作凭据。」

## 配置

| 键 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 插件开关 |
| `model` | `deepseek/deepseek-flash` | 分析用的模型，写 `供应商/模型` |
| `thinking` | `high` | 思考强度 `off` / `minimal` / `low` / `medium` / `high` / `xhigh`；留空交给接口默认 |
| `days` | `0` | 只统计最近多少天；0 表示全部留存记录 |
| `max_samples` | `120` | 交给模型的样本条数 |
| `max_scan` | `8000` | 一次最多读多少条本人记录 |
| `partners` | `6` | 报告里最多摆几个往来对象；0 表示不算这一段 |
| `theme` | `auto` | `auto` / `light` / `dark` |
| `image_enabled` | `true` | 是否出卡片图；关掉或渲染失败时退回一份等价的文字版 |
| `image_scale` | `3.0` | 出图倍率，1—4 |
| `cooldown_seconds` | `180` | 同一个目标两次生成之间的最短间隔；这期间再问重发上一次的结果 |
| `channel` | 空 | 群名单，语义同 `[stats.channel]`；**两边都留空就是对所有群生效**，不需要单独开群 |

思考强度默认 `high`：九格要先读完一百多条样本再落笔，调低会让结论只停在「话多话少、白天黑夜」那一层。

注意 `days`、`max_samples` 与 `partners` 会改变下发的素材，也就改变了这份画像。

## 频次限制

同一个目标同时只允许一次生成。`cooldown_seconds` 之内再问一次，不重新生成，而是把上一次那张卡片（出图失败时是那段文字）原样再发一遍。冷却期里同一批素材算出来的还是同一份，重复生成只会多付一次模型与出图的钱。缓存只留最近问过的那几个人，被挤掉、或者上一次压根没发出东西时，退回一句「刚画过，N 秒后再来」。两道闸只拦发指令的人，不影响其它功能。

## 端到端验证

```sh
cargo test --release portrait_live -- --ignored --nocapture
```

它读 `config.toml` 与 `data/bot.db`，跑真模型、出真图，打印往来账、九格档案与收口后的综述，并把出图写到临时目录。目标默认取记录最多的人，也可以用 `PORTRAIT_LIVE_USER=<QQ号>` 指定。

只想看版式、不联网（把日读、夜读与降级三份 HTML 写出来）：

```sh
PORTRAIT_CARD_DUMP=$PREFIX/tmp/portrait cargo test portrait::card::tests::dump -- --ignored
```

## 界面取自哪里

色值、字号、圆角、间距一律取 `res/cards/m3e.css` 的令牌，版式层不写数值。这套令牌属于个人设计系统，规范本体在 `github.com/araea/design-system`，本仓库不放副本。
