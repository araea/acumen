# 用户画像

读一个群成员的历史发言，给他出一份分层的**人格画像**，出一张图文报告。指令是 `画像`。

## 三层，从硬到软

画像在这里分三层，读者对它们的信任度该一路往下走。这也是这份东西的诚实所在：它说明了自己哪些部分算得出来、哪些是读出来的、哪些只是照框架画的一道影子。

| 层 | 是什么 | 谁产出 | 版式 |
| --- | --- | --- | --- |
| 仪器读数 | 读数统计 + **语言指纹**：提问率、感叹率、笑声、语气词、长度起伏、爆发指数…… | 全部由 `collect.rs` 从库里数出来，不经模型 | 一排事实筹码 |
| 读法 | **行为标签**（活跃/内容/交互/表达四维，事实/统计/推断三层）+ 一段**语言风格白描** | 模型读那些事实 | 三层徽章的标签 + 衬线一段 |
| 投影 | **MBTI 四轴光谱**与**九型核心** | 模型把行为往两套既有框架上做的读数 | 两把尺子画成的光谱 |

两个性质写在报告上。**可核验**：仪器读数每一条都回得到原始记录，读法的引语逐字出自样本。**有损**：没观测到的部分一句话也没有。

投影层是这次的重点，也是全篇最需要把话说清楚的地方：MBTI 与九型是**把群聊行为往既有框架上做的投影，是讨论的起点，不是定论**。一个人打过的字支撑得起一条语言风格、一套作息与交互习惯，支撑不起一句「此人是 INTJ」。所以光谱画的是「往哪一侧偏了多少」，不是「是或不是」；贴近中线的人画出来就是一条贴中的短线。

## 为什么只有两把尺子，不是四把

人格框架彼此高度重叠。MBTI 的内外倾、直觉实感、思考情感，就是大五的外向性、开放性、宜人性；荣格的八个认知功能又是同一份数据换一种拆法。把它们一起摆上来看似「多维分析」，其实是同一份证据讲了四遍，还更唬人。

只留两把**各答一个别的问题**的尺子：

- **MBTI 四轴**答「他往世界哪一侧使劲」——气质与风格，可量化、可讨论。
- **九型核心**答「他为什么这样使力」——动机与恐惧，这是 MBTI 结构上给不出的那一问。

一把说「怎么样」，一把说「为什么」，不重叠。

## 用法

| 指令 | 说明 |
| --- | --- |
| `/画像` | 查看自己的画像 |
| `/用户画像` / `/我的画像` / `/画像报告` | 同上 |
| `/画像 @某人` | 查看对方的画像 |
| `/画像 <QQ号>` | 按 QQ 号查看 |

关键词之后只允许空白、`@`、一串数字，或者「报告」两个字，其余一律不算指令。日常闲聊里说到「画像」这个词不会触发模型调用。

唯一的例外是消息里带了明确的 `@`：平台会把「@某人的名字」也写进文本段，于是关键词后面常常跟着「黑猫警长」以及他随口的半句话。目标是谁已经写在 `@` 里，这时候不再要求后面只能跟空白与数字。前缀也可以躲在名字后面，`@小黑 /画像` 与 `/画像 @小黑` 都认。消息里 `@` 机器人自己不算目标，会退回成查自己。

没有 `算卦`、`起卦` 这类别名。这个插件只做一件事。

## 报告的结构

| 区块 | 内容 |
| --- | --- |
| 综合速写 | 4—9 字的称谓，加一句话概括——这份东西的脸 |
| 人格投影 | MBTI 四轴光谱（含参考码与常称）+ 九型核心（型号、常称、一句核心理念） |
| 语言指纹 | 一排事实筹码 + 模型对它们的一段读法 |
| 行为标签 | 四个维度下的标签，每条带抽象层级与证据 |
| 画像综述 | 四到六段白描，段落与引语交织，引语落在论证里，不贴到文末 |
| 群聊钩子 | 1—3 条能拿去讨论的切入点 |
| 页脚 | 观测区间、样本条数、模型，以及那句「不等于本人」 |

没有分点罗列，没有刻度条，没有卦象。

## 语言指纹

这是旧版漏掉、新版补上的那块：**这个人是怎么说话的**。全篇唯一算得出来的东西，因此放在仪器读数层，最硬。

分母统一用**可读发言**（`length > 0` 且去掉纯占位标记后仍有字的那些条），空消息、纯图片纯表情不进这一层。字段都写在 `collect.rs` 的 `Style` 里：

| 字段 | 读什么 |
| --- | --- |
| 提问/感叹/省略率 | 以 ？？、！！收尾，或含省略号的消息占比 |
| 笑声/语气词率 | 含「哈哈 / hh / 233 / 笑死」与「吧呢哦啊嘛啦诶呀」的占比 |
| 自称/对称呼密度 | 每百字「我俺咱」「你您」出现次数——说给自己听还是对着人说 |
| 长度起伏 | 消息长度变异系数，匀称还是时短时长 |
| 长短占比 | 长消息（≥40 字）与短消息（≤5 字）各占多少 |
| 爆发指数 | 发言间隔的 (σ−μ)/(σ+μ)：-1 极匀、0 随机、接近 +1 一阵一阵 |
| 相邻重复 | 与上一条内容相同的占比——口头禅、复读机倾向 |

这些数一路喂给模型的提示词，也是卡片上那一排筹码。

## 行为标签

四个维度固定，不许模型自创。某个维度没有标签就整块不印。

| 维度 | 读的是 |
| --- | --- |
| 活跃 ACTIVITY | 什么时候出现，去得勤不勤，密度如何 |
| 内容 CONTENT | 说什么，反复说什么，哪些话题从来不碰 |
| 交互 INTERACTION | 跟谁说话，主动发起还是接话，他说的时候别人接不接 |
| 表达 EXPRESSION | 怎么说：长短、句读、用不用图片表情语音 |

每条标签还要标出它的抽象层级，只有三层，从事实到推断：

| 层级 | 含义 | 版式 |
| --- | --- | --- |
| 事实 OBSERVED | 观测即得，不做推断。条数、时刻、占比、媒介构成、原话 | 浅底徽章 |
| 统计 DERIVED | 把观测按一个阈值归成一类，阈值要一起写出来 | 淡主底徽章 |
| 推断 INFERRED | 从样本的意思里读出来的，一条必须有一条原话或一组数字顶着 | 主色实心徽章 |

提示词对标签的条数有硬性规定：每个维度 2 到 4 条，整个画像 8 到 16 条，**推断标签不超过总数的一半**。认不出维度的标签收口时直接丢掉（`persona.rs` 的 `dimension_of`）。一个维度最多印四条，四个维度都得有位置。层级认不出来的一律按**推断**处理，没标「观测即得」的不按事实读。

### 样本充分性

读数那一行最末一格给的是这份画像能信到什么程度，阈值写在 `collect.rs` 的 `Sufficiency` 里：

| 判定 | 条件 |
| --- | --- |
| 充分 | 发言 200 条以上，且活跃 14 天以上 |
| 一般 | 发言 50 条以上，且活跃 5 天以上 |
| 有限 | 其余 |

## 两把尺子怎么打分

`models.rs` 只定义框架、做归一、给卡片取值；**打分在模型侧做**，因为那要把行为读进框架，是语义活。

- **MBTI**：四轴各一个 -100..100 的整数，正 = 靠向 E/S/T/J，负 = 靠向 I/N/F/P，绝对值 = 强度。多数人贴近中线，模型被要求拿不准就给接近 0 的数，只在证据清楚时才给大数。四联码是光谱的副产品，不是结论。
- **九型**：一个 1..9 的主型加一个相邻侧翼（一号两翼 9 与 2，九号两翼 8 与 1）。它答的是「他为什么这样行事」。

收口时全部夹回合法区间：MBTI 越界夹回 ±100，九型主型不在 1..9 整块作废、侧翼不相邻就只留主型。参见 `models.rs`。

## 提示词

`persona.rs` 的 `SYSTEM_PROMPT` 按三层来写：先说画像分仪器读数、读法、投影三层；再分别交待——事实与语言指纹怎么用、四维标签与三层抽象怎么分、两把尺子怎么打、群聊钩子怎么写；最后定综述笔法。笔法是白描，一句话说一件事写成完整陈述句，每一句判断后面要有他说过的话、数字或时间撑着。不用比喻、对仗、金句与格言体，不用评价词与模糊限定。数字一段里至多两三处。另外明确要求不写外貌、性别、年龄、地域、收入、健康与政治立场，也不臆断具体职业、住处与私人关系。

模型返回一个固定字段的 JSON。**引语必须逐字出自样本**，收口时按归一化（去掉标点与空白）比对，对不上的丢掉，报告里不出现编出来的「他说过」。

## 报告的来源

分成四步。

1. 采集。只读 `message_records`，范围是该用户在群里的发言（`group_id != 0`），并排除 `role = 'self'`。本机机器人与号主共用同一个 QQ 号，记录靠 `role` 区分人和机，不排除就会把机器人自己说的话算到号主头上。统计发言总数、活跃天数、24 小时与星期分布、常在的群、消息类型构成与高频词；再扫一遍可读发言，算出语言指纹。发言样本按时间等距抽取，并保证最长的几条入选。
2. 分析。统计量、语言指纹与样本交给模型，要求返回一个固定字段的 JSON。这是唯一花钱的一步。模型不接时报告仍然成立——仪器读数与统计直出的标签都在，投影层整块消失。
3. 收口。字数、条数、维度、层级、两把尺子的合法区间、引语逐条核对。
4. 出图。HTML 模板截图，版心 720 CSS 像素。日读与夜读两套纸色主题，按北京时间 07:00—18:59 自动切换。显示级的文字（综合速写、九型名、语言读法、综述、引语）用衬线，其余用无衬线。报告开头的头像按 QQ 号从 QQ 公开头像 CDN（`q.qlogo.cn`）取回，转成 data URL 内嵌进 HTML。取不到时用名字首字代替。出图失败时退回一份文字版。

**模型调用失败、超时或 JSON 解析失败时仍然出报告**：语言指纹的筹码照印，标签退回统计直出（只有事实与统计两层），综述只写一句事实，投影层留空并标「模型未接，人格投影这一层空着」，综合速写挂一枚「模型未接，标签由统计直出」。投影要用伪精度去补一份没读过语义的 MBTI 是不诚的，所以这一层宁可空着。

每一次生成的 HTML 会写到 `data/portrait/`，保留最近 40 份，可以用来核对版式。

## 数据去向

报告本身不发原始记录，但下面这些内容会发给 `model` 指向的模型接口：

- 统计数字与高频词；
- 语言指纹的各项比例；
- 最多 `max_samples` 条发言样本，每条截断到 90 字，总量不超过 9000 字；
- 对象的群名片与 QQ 号。

接口地址由 `model` 的供应商前缀决定，见 `[oai.providers]`。提示词明确要求模型不写外貌、性别、年龄、地域、收入、健康与政治立场，也不臆断具体职业、住处与私人关系。

出图之前还会向 `q.qlogo.cn` 请求一次该 QQ 号的头像，只取图，不上传任何内容。

报告页脚写着「画像是对行为的抽象，有损：只含他在群里说过的部分，不等于本人。MBTI 与九型是行为往框架上的投影，是讨论的起点，不是定论。仅供娱乐，不作凭据。」

## 配置

| 键 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 插件开关 |
| `model` | `deepseek/deepseek-flash` | 分析用的模型，写 `供应商/模型` |
| `thinking` | `high` | 思考强度 `off` / `minimal` / `low` / `medium` / `high` / `xhigh`；留空交给接口默认 |
| `days` | `0` | 只统计最近多少天；0 表示全部留存记录 |
| `max_samples` | `120` | 交给模型的样本条数 |
| `max_scan` | `8000` | 一次最多读多少条原始记录 |
| `theme` | `auto` | `auto` / `light` / `dark` |
| `image_enabled` | `true` | 是否出卡片图；关掉或渲染失败时退回一份等价的文字版 |
| `image_scale` | `3.0` | 出图倍率，1—4 |
| `cooldown_seconds` | `180` | 同一个目标两次生成之间的最短间隔；这期间再问重发上一次的结果 |
| `channel` | 空 | 群名单，语义同 `[stats.channel]`；**两边都留空就是对所有群生效**，不需要单独开群 |

思考强度默认 `high`：标签、风格读法与两把尺子要先读完一百多条样本再落笔，调低会让结论只停在「话多话少、白天黑夜」这一层。

注意 `days` 与 `max_samples` 会改变下发的素材，也就改变了这份画像。

## 频次限制

同一个目标同时只允许一次生成。`cooldown_seconds` 之内再问一次，不重新生成，而是把上一次那张卡片（出图失败时是那段文字）原样再发一遍。冷却期里同一批素材算出来的还是同一份，重复生成只会多付一次模型与出图的钱。缓存只留最近问过的那几个人，被挤掉、或者上一次压根没发出东西时，退回一句「刚画过，N 秒后再来」。两道闸只拦发指令的人，不影响其它功能。

## 端到端验证

```sh
cargo test --release portrait_live -- --ignored --nocapture
```

它读 `config.toml` 与 `data/bot.db`，跑真模型、出真图，打印标签表与收口后的画像，并把出图写到临时目录。目标默认取记录最多的人，也可以用 `PORTRAIT_LIVE_USER=<QQ号>` 指定。

只想看版式、不联网（把日读、夜读与降级三份 HTML 写出来）：

```sh
PORTRAIT_CARD_DUMP=$PREFIX/tmp/portrait cargo test portrait::card::tests::dump -- --ignored
```
