# 知微：名称与界面复审

## 名称结论：中文名「知微」，英文名 Acumen

审计对象是 Acumen 当前实际能力：Satori 群聊接入、搭话与记忆、用户画像、消息统计，以及媒体、资讯、管理等 23 个插件。中文名是整个机器人的身份，英文名与仓库名是同一身份的对外标识；2026-09-20 之前英文标识沿用旧缩写 `ayjx`，与「知微」对不上，本轮统一为 `acumen`。

| 维度 | 判断 |
| --- | --- |
| 核心逻辑 | 搭话先理解上下文，画像从日常发言积累印象，「知微」能概括观察、理解再回应的过程 |
| 能力边界 | 名称没有承诺全知或全自动管理；媒体与管理插件可以自然归入这一机器人身份，不必逐一写进名字 |
| 中文气质 | 两字简洁、读音清楚，含义克制；「知微知彰」的文化联想成立，但不作为算法能力证明 |
| 英文名 | `Acumen`（敏锐、对细微之处的洞察）直接落在「知微」的核心，词形短、读音清楚，与接入端 `satori` 的命名气质相配 |
| 识别连续性 | 与接入端「知弦」的中文命名语言不变；英文标识从 `ayjx` 收成 `acumen`，仓库、二进制、服务与请求头一次对齐，中文显示名不动 |
| 限制 | 这是产品语义和体验审计，未作商标、应用商店名称唯一性或注册可用性判断 |

因此中文名保留「知微」，英文名定为 `Acumen`、标识统一为 `acumen`。README 原先过长的更名辩解收为产品说明，把历史与判断留在本审计中；名字要有可核对的语义，不追求与能力无关的抽象“高级感”。

## 图标复核

2026-09-23 图标重做：M3 Expressive 形状库的七瓣「曲奇」形挖出一个焦点圆——整体是被观察的事物，那一点是看见的细处；底板为连续曲率的超椭圆。生成源仍是 `scripts/make-icon.py`，位图由 Chromium 渲染同一份 SVG。标记外径 32.6 / 54（半径），处于 33 的安全圆内；maskable 与 Apple touch 为不透明满底方角，单色版透明底纯白。

平台边界需要明确：这是可安装网页，manifest 的 `maskable` / `monochrome` **不等于**原生 Android `AdaptiveIconDrawable` 的 foreground/background/monochrome 资源。桌面主题着色取决于浏览器与启动器支持。项目也没有原生 Apple 应用，因此没有宣称提供 Icon Composer 多层图标、深色/着色原生资产。若将来封装原生应用，应沿用几何另行提供平台资源。

## 本轮界面变更

沿用 `res/cards/m3e.css` 的共同色彩、形状和语义令牌；所有插件配置从同一注册表与表单组件生成。插件卡片仍使用同一系统，群聊缩略图的阅读字号保留；控制台单独覆盖阅读字号，避免缩小群里收到的图。

- 默认紧凑：正文 13px，说明 12px，标题 15/24px；设置中提供舒适档，并仅在当前浏览器持久保存。手机输入保持 16px，避免聚焦时自动放大。
- 导航抽屉从 264px 收到 216px，内容用色调容器分层；插件选中项、搜索、配置区域共用组件角色。
- 总览主动作保留强调色与不对称形状；最近日志横跨宽屏内容区，减少长消息在窄列里的折行。
- 日志重组为工具栏、连接状态、阅读区和计数条。跟随、筛选、导出及清屏有独立位置；减少动态效果与 48px 触控范围继续适用。

这些是针对中文运维界面的 Web 实现，不宣称为 Google 官方组件或原生物理弹簧实现。

## 日志故障与修复

1. **面板缩小后末行不可见。** 原实现只有插入日志才贴底，无新行时改变视口高度会留下过期的滚动位置。真实 Chromium 回归先在旧版失败；现在 ResizeObserver 在跟随模式下按实际布局重新贴底。
2. **稀疏筛选结果被突发日志丢弃。** 原队列先裁到 80 行再过滤，前部的一条 WARN 会被后部 300 条 INFO 挤掉。现在先过滤再限制显示队列，完整缓冲仍最多 2000 行。
3. **滚动事件被当成阅读意图。** 程序贴底产生的延迟事件可能取消刚点下的暂停。现在记住已知位置，只让实际向上移动暂停，实际回到底部恢复；关闭滚动锚定以避免浏览器在批量删旧行时自行挪动位置。
4. **后台返回覆盖暂停阅读。** 同一面板已暂停时不再重画现有 DOM；新快照只替换缓冲，保留位置和选区，点回到最新再显示新记录。

仍保持 100ms 合批、一次最多插入 40 行、DOM 最多 80 行，以及非事件流响应后的退避重连。日志导出仅包含当前筛选的内存缓冲；它不是完整历史归档，完整日志仍在终端。

## 验证入口

`cargo test --locked` 检查共享设计令牌、内嵌资源、注册表与后端逻辑；`node tests/console.cjs` 用隔离 HTTP 夹具和真实 Chromium 覆盖操作、320/390/800/1400px、深浅主题、密度持久化、减少动态效果、日志突发/筛选/缩放/暂停/前后台/断线恢复；`node tests/console-backend.cjs` 验证实际 release 的内嵌资源、鉴权与 SSE。测试实例不接真实聊天平台。
