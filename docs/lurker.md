# 潜水清理

群规要求成员保持活跃的群，管理员原先只能一个个手动踢，或者用 QQ 自带的「不活跃成员」筛选——后者看不到每个人具体多久没说话，也没有豁免、提醒和节奏控制。「潜水清理」把这件事做完：查名单 → 看 → 挑人 → 确认 → 慢慢移出 → 报结果。

插件默认开着，但只有群主、群管理员与机器人管理员能用，而且**不确认就不会移出任何人**；自动清理默认关。

## 在群里用

| 指令 | 做什么 |
| --- | --- |
| `潜水` | 查一遍本群，发名单（长图 + 文字版，装在一条合并转发里）。写 `潜水 60` 只这一次按 60 天看 |
| `潜水 踢 1-20 25` | 移出这些序号的人。会先说清是谁、要多久，**同一个人两分钟内回「确认」**才动手，回「取消」作罢 |
| `潜水 踢 全部 除 3 7` | 序号的写法：区间 `1-20`、几段 `1-5 8 10-12`、`全部`、排除 `除 3 7` 或 `!3` |
| `潜水 提醒 1-20` | 先 @ 他们打个招呼，说清宽限到哪天（`warn.grace_days`，默认 3 天） |
| `潜水 进度` / `停` / `继续` | 看进展；下一个人之前停下；接着做被重启打断的那批 |
| `潜水 豁免 @某人` | 这个人以后不进本群的名单；`潜水 取消豁免 @某人`；只发 `潜水 豁免` 看名单 |
| `潜水 天数 45` | 本群改成 45 天没说话算潜水；`潜水 天数 默认` 照全局 |
| `潜水 记录` | 最近几次移出了谁、谁确认的 |

序号认的是**最近一次「潜水」发出的那份名单**（24 小时内有效）：管理员看到的是哪些人，移出的就只能是这些人。

## 名单

一人一行：序号、头像、群名片（昵称不同时另写）、QQ 号、群等级、头衔、进群日期；右边是多久没说话、最后说话那天。按沉默时长分节（一年以上、半年以上、三个月以上……），最久的排第一。一张图放 `list.rows_per_image` 行（默认 50），长了切成几张；合并转发里另附文字版，能搜、能复制号码，出图失败时它就是名单本身。

不进名单的人：机器人自己、群主与管理员、号主与机器人管理员（`ctl.admins`）、豁免名单（全局 `exempt` 与每群 `groups.<群号>.exempt`）、群等级到 `protect_level` 的人；`protect_titled` 打开时有群头衔的也不动（默认关：不少群的头衔是群友自己领的）。进群不满天数的新人也不算——除非打开 `newcomer_days`（进群满这么多天还一句没说也算，防进群就潜的小号）。

`min_messages` 写成 3，就是「30 天里说不到 3 句」也算（单列一节「说得太少」）。条数只数机器人收到的消息。

## 不冤枉人

机器人离线那几天群里说过的话它收不到。只看自己的消息记录，号主关了几天机器人、回来一查，那几天说过话的人就全成了「潜水」。所以：

1. **先看 QQ 自己记的最后发言。** 知弦 0.39 起，成员资料带 `last_sent_at`——QQ 服务器那边记的，机器人不在线的日子它也知道。每次查都让知弦先向服务器重拉名单。
2. **再拿机器人亲眼看到的核一遍。** 最近三天机器人见过说话的人里，QQ 的记录要大多跟得上（八成），才信它；跟不上（读到了旧缓存）就不拿它下结论。两份取较晚的那个：谁说过话就算谁说过。
3. **QQ 靠不住时，只在机器人记录没断的那段里下结论。** 插件每五分钟记一次「事件连接通着、消息记录开着」（`data/lurker/watch.json`），再并上从收到过的消息推出来的在线时段（连着三小时一条都没收到才算断）。从此刻往回、记录一直没断的那段比口径的天数短，就说不了「这期间他一句没说」——这些人列进「**待观察**」：不编号，所以任何序号区间都圈不到他们，名单开头也会说清记录从哪天起才完整。

## 移出

- **慢**：两次之间隔 `pace.interval_seconds`（默认 4 秒，上下浮动四分之一），每移出 `pace.burst` 人歇 `pace.rest_seconds` 秒（默认 15 人歇 40 秒），100 人约 11 分钟。所有群共用一条队列，两个群同时清也不会翻倍提速。一次确认最多 `pace.max_per_run` 人（默认 100）。
- **动手前再看一眼**：排队期间说了话的人留下，自己退了群的跳过；一连三次失败、或者像是没了权限，就停下来。
- **以名单为准报结果**：全部过完再拉一遍名单，按「还在不在群里」改正结果，在群里回一句「移出 18 人，用时 3 分钟；2 人刚说过话、留下」。
- 入群欢迎不会给这些人逐个送别。进行中的这批会拦着例行重启；进程中途还是退出了的话，剩下的人记在 `data/lurker/jobs.json`，连上后在群里说一声，「潜水 继续」接着来。
- `permanent = true` 时移出的人不能再申请加群。

## 控制台

插件页的「潜水名单」一节：选群、查一遍（可临时换天数），按类别筛（很久没说话 / 进群后没说过话 / 说得太少 / 待观察）、按名字号码头衔找，勾人或按序号区间选，再「提醒」或「移出」。移出前的确认框列出每个人与大约要多久；移出时显示进度，可以随时停。每行右边一枚「豁免」，点了这个人以后就不进这个群的名单（可撤销）。下面是「最近的移出」：谁确认的、移出了谁。

## 自动清理（默认关）

`[lurker.auto]` 打开后只管 `auto.groups` 里点了名的群。每天 `auto.time`（之后两小时内，错过就等明天）看一遍：

1. 提醒满宽限期还没冒泡的，移出——每群一次最多 `auto.max_kicks` 人；
2. 到了 `auto.weekdays` 里的日子，给新查到的人发提醒（`auto.warn = false` 时不提醒，到日子直接移出）。

查出来的人超过全群的 `auto.max_ratio`%（默认 15）就不动手，私聊告诉号主与机器人管理员去看一眼——多半是哪里出了岔子，而不是真有那么多人潜水。机器人不是管理员的群跳过并说一声。做完在群里说一句（`auto.announce_text`，可写几种说法）。
