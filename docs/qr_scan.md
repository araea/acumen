# 二维码识别与生成

两个方向，一组指令：图里的二维码转成文字与链接；文字与链接转成一张好扫的二维码图

- [识别](#识别)：`/扫码`，附图或引用一张图
- [生成](#生成)：`/生成二维码 内容`，或引用一条消息

`/二维码`、`/qr` 两头都沾：有图就识别，没图而后面有文字就生成。

## 识别

### 用法

```text
/扫码          （附一张图，图在指令前后都行）
/扫码          （引用一条带图的消息）
```

别名 `识别二维码`、`二维码`、`qr`、`qrcode`；指令词后须有空白或结尾。只响应指令，不扫群里的每一张图。

一次可附多张图（默认最多 4 张），也可引用一条带多张图的消息。处理过程不发提示，结果引用请求那条；只有没找到图、读不了图或什么码都没识别出来时才回一句，并给出下一步。

### 输出

结果用文字，不用图片。一个码一行标题、下面是内容，内容原样放在单独一行：

```text
🔗 链接 · github.com
https://github.com/araea/acumen
```

多个码按阅读顺序（自上而下、同一行自左而右）编号，标好序号的原图发在清单前面，序号与图上一一对应：

```text
识别到 3 个二维码

① 🔗 链接 · github.com
https://github.com/araea/acumen

② 📶 Wi-Fi · MyHome
密码 secret123
加密 WPA

③ 📝 文本
你好
```

可识别类别：链接（带已知站点名，如微信名片、QQ 群、支付宝、各家短链）、Wi-Fi、电话、短信、邮件、位置、名片（vCard 与 MECARD）、日程、微信收款码、唤起应用的自定义协议、纯文本。链接里的协议与域名转小写（支付宝收款码整串大写），路径不动。

两步验证二维码（`otpauth://`）不回显密钥，只说它是什么、哪个账号。`javascript:`、`data:`、`file:` 这类不是网页的链接单独标出。单条内容超过 800 字时截断并写明全长。

### 识别能力

引擎是 [`rxing`](https://crates.io/crates/rxing)（zxing-cpp 的移植），一次扫出一张图里全部的 QR 与 Micro QR、rMQR。认不出来时按顺序再试：缩小一半与四分之一、放大小图、全局直方图二值化、反色、拉伸对比度；透明底的 PNG 先垫白。非 UTF-8 载荷（国内早年生成器塞进去的 GBK）会重判，不显示成乱码。

## 生成

```text
/生成二维码 https://github.com/araea/acumen
/生成二维码 github.com/araea              （裸域名自动补 https://）
/生成二维码                               （引用一条消息：把它的文字转成二维码）
/二维码 你好                               （没有图，后面有文字：同样是生成）
```

别名 `转二维码`、`做二维码`、`二维码生成`、`qrgen`；指令词后须有空白或结尾。内容里的换行、空格、符号、网址里的 `&` 原样编码，只去掉首尾空白。

指令后面没写内容时，转的是所引用那条消息里的文字，不用再复制粘贴一遍。指令里自己写了内容就以它为准。

结果是一张图，引用请求那条，平常不带多余的话。只有两种情况会在图后补一句：

- 内容是没写协议头的网址（`github.com/araea`），补成 `https://github.com/araea`，并把补完的整串单独放一行，方便复制。只认常见后缀（`.com`、`.cn`、`.io` 等）的单独一串，所以 `main.rs`、`notes.md`、`v1.2.3` 这类不会被当成网址。
- 内容较长、二维码很密（约 85 格以上）时提醒：扫不出来先把图放大，或缩短内容。

一个码最多装约 980 个汉字或 2900 个英文字符；超出会说明并建议先放到网页或文档里，再用链接生成。

图为纯黑白、白底、四周留足静区，方格按整数像素放大，不上色、不加图标——花样越多，越容易有扫码器读不出来。大小按格数调：小码约 700 像素见方，密码每格不少于 6 像素。纠错等级先取 M（损一成多仍可读），内容太多再降到 L 换最大容量。

生成的图可以直接交给 `/扫码`，读出来与输入一字不差；测试里逐项核对了中文、emoji、多行与长文本。

生成的内容不写进日志，只记字数与格数（内容可能是密码）。

## 配置

配置位于 `config.toml` 的 `[qr_scan]` 段，完整示例见 [`config.example.toml`](../config.example.toml)。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `max_images` | `4` | 一次最多识别几张图，1–8 |
| `max_codes` | `12` | 一张图最多找几个码，也是一条回复最多列几个，1–50 |
| `annotate` | `true` | 一共不止一个码时，把标好序号的原图一起发回来 |
| `timeout_seconds` | `30` | 下载加识别的总预算，5–120；到点用已经找到的结果收工 |
| `generate` | `true` | 是否提供文字转二维码；关掉后生成类指令词不响应，`/二维码`、`/qr` 只当识别用 |

## 测试

```sh
cargo test --bin acumen qr_scan
```

识别的测试用 `qrcode` 库现场生成二维码，拼进九宫格、反色、旋转、噪声照片、透明底等场景；Micro QR 用另一个编码器生成的固定样张。生成的测试把成品图交给识别引擎读回，要求与输入一字不差。
