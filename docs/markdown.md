# Markdown 转图

把 Markdown 渲染成图片。指令后直接写内容，或引用一条消息再发指令，机器人回复一张排好版的图；长文按页发在同一条消息里。

## 用法

```text
/md # 标题
正文，**加粗**、`代码`、[链接](https://example.com)
```

也可以引用一条消息，只发 `/md`。指令后写了内容时以指令后的内容为准。别名 `markdown`、`渲染`；指令词后须有空白或换行。

整段被 ` ```markdown ` 围栏包起来的内容会先脱掉围栏（常见于为防止聊天软件吃掉星号而整段包成代码块）。

处理过程不发提示，结果引用请求那条。只有用法错误时才回复，并给出下一步：没有内容、引用的消息没有文字、超出字数上限、渲染失败。

## 支持的语法

| 语法 | 渲染 |
| --- | --- |
| 标题 `#`–`######` | 五档字阶；二级标题带主色短竖，页尾不留孤标题 |
| 强调、加粗、删除线 | 单个 `~`（如 `10~20`）不当删除线，只有 `~~` 才是 |
| 列表、嵌套列表、任务清单 | 有序列表保留起始序号；复选框带勾，不只靠颜色 |
| 引用、GFM 提示块 | `[!NOTE]` `[!TIP]` `[!IMPORTANT]` `[!WARNING]` `[!CAUTION]`，带文字标签与图标 |
| 表格 | 保留对齐；五列及以上收小一档字号 |
| 代码块 | 语言标签；Rust、Python、JS/TS、Go、C/C++、Java、Kotlin、C#、Swift、PHP、Ruby、Lua、SQL、Shell、JSON、YAML、TOML/INI、HTML/XML、CSS、diff 着色，其余语言原样显示 |
| 脚注、定义列表 | 脚注编号与内容列在所在页底 |
| 公式 `$…$` `$$…$$` | 不排版，按等宽显示 LaTeX 源码 |
| 文首 YAML 头 | 有 `title` 时作为文档标题，`author`、`date` 等作为副行 |
| 链接 | 文字带下划线与编号，完整地址列在所在页底；自动链接本身就是地址，不编号 |
| 图片 | 不加载，留一个带替代文字的占位 |

单个换行按换行显示（聊天里的写法）；关闭 `keep_line_breaks` 后按 CommonMark 并成一段。

## 安全边界

卡片是静态位图，不生成 `href` 与 `src`，也不加载任何外部资源：图片地址由发送者控制，让浏览器去取等于让机器人替群友访问内网。原始 HTML 一律当文字显示，`<br>` 除外，HTML 注释被忽略。

## 排版与分页

排版遵循 M3 Expressive 令牌与字阶，Apple HIG 与 WCAG 2.2 AA 作为交互与无障碍依据，与其他卡片共用 `res/cards/tokens.css` 与 `m3e.css`，本卡的元素样式在 `res/cards/markdown.css`。

- 卡宽默认 560px、正文 18px、行高 1.6，每行约 28 个汉字：图要在手机上全屏看，决定「一屏能读多少」的不是卡宽本身，而是字号与卡宽的比例。字相对卡宽越小，一行塞得下的字越多，眼睛不必频繁换行，扫读才快。
- `font_size` 缩放整套字阶（标题、代码、表格、页脚同步变小），间距令牌是 px 定值、不跟着缩，所以密排不会把内容挤成一坨。
- 层级靠字阶、字重与一小块色，色块只留给另一类内容（代码、引用、提示、表格、页底附录）。
- 强调靠字重，链接靠下划线与编号，任务靠勾，都不只靠颜色。
- 代码着色取自 M3 角色色；测试用 `tokens.css` 的真实色值，逐对检查浅色与深色下用到的前景与背景对比度不低于 4.5:1。

分页按块估高：超过 `page_height` 就另起一页，标题不落在页尾；过长的代码块按行拆开，表格按行拆开并在每页重复表头，顶层长列表按项拆开并延续序号。估高只决定断在哪里，不影响排版。总页数超过 `max_pages` 时只发前几页并在消息里说明。

## 配置

配置位于 `config.toml` 的 `[markdown]` 段，完整示例见 [`config.example.toml`](../config.example.toml)。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `theme` | `light` | 配色：`light` 或 `dark` |
| `width` | `560` | 卡面宽度（CSS 像素），320–1200 |
| `font_size` | `18` | 正文字号（CSS 像素），14–26；整套字阶跟着缩放 |
| `image_scale` | `2.0` | 出图倍率，1–4 |
| `page_height` | `2000` | 每页目标高度（CSS 像素），600–8000；不拆的块可略超 |
| `max_pages` | `6` | 最多发几页，1–10 |
| `max_chars` | `20000` | 单次最多渲染多少字，100–100000 |
| `keep_line_breaks` | `true` | 单个换行按换行显示 |

## 与 oai 回复卡的关系

`oai` 的回复卡有自己的渲染（单张卡、参考来源与工具轨迹附录），与本插件职责不同、各有取舍，互不共用。
