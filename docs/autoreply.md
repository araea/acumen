# 自动回复

群里有人问到设好的触发词，自动回一句。新人进群总是那几个问题（下载地址、群规、怎么用），管理员设一次就不用再手打。

规则存在 `data/autoreply/rules.json`。有两处可以改，改的是同一份数据：控制台插件页的「回复规则」，以及群里的「自动回复 …」指令。`config.toml` 的 `[autoreply]` 不存规则，只管回复的方式：冷却、限流、包含匹配的字数上限、谁能用指令。

## 一条规则

| | |
| --- | --- |
| 触发词 | 可以写好几个，任一对上就回。比较前，消息和触发词都会去掉空格和标点、全角转半角、不分大小写，所以「怎么下载？」和「怎么 下载」算同一句 |
| 怎么比 | **精确**：整句一样才回，最不会误触。**包含**：句子里有触发词就回。**开头**：以触发词开头就回。**正则**：对原文做正则匹配，不分大小写 |
| 回复 | 可以写几种说法，每次随机发一种。文字里能插图、表情和占位符；也可以整条存一段合并转发 |
| 范围 | 只在某几个群回，或所有群共用。共用规则可以在个别群停用 |
| 其他 | 只在 @ 机器人时回；折成合并转发发出（长内容不刷屏，回复里单独一行 `---` 把内容分成几条）；单独设冷却时间；私聊里也回（只对所有群共用的规则有效） |

回复里能用的占位符：

| 写法 | 效果 |
| --- | --- |
| `{at}` | @ 提问的人 |
| `{name}` / `{user_id}` | 提问人的群名片（没有就用昵称）/ 账号 |
| `{keyword}` | 这次对上的触发词 |
| `{group}` / `{group_id}` | 群名 / 群号 |
| `{greeting}` `{time}` `{date}` `{weekday}` | 早上好…、21:05、10 月 22 日、星期三（北京时间） |
| `{image:文件名或链接}` | 一张图。控制台里点「插入图片」会自动上传并写好 |
| `{face:14}` | QQ 表情 |
| `{甲\|乙}` | 每次随机换成其中一个 |

## 防误触

下面几道关按顺序检查，任何一道拦下就不回：

1. 包含匹配的触发词至少要两个字；而且只看 `contains_max_chars`（默认 40）字以内的消息，长消息里顺口提到关键词，多半不是在提问。
2. 以指令前缀开头的消息不回，留给指令处理。机器人自己说的话、`ignore_users` 里的账号也不回。
3. 规则可以设成只在 @ 机器人时才回。
4. 冷却：同一条规则在同一个群里，隔 `cooldown_seconds` 秒（默认 30，规则自己可以另设）才回第二次；同一个人反复问同一个问题，隔 `user_cooldown_seconds` 秒（默认 120）才再回他；每个群每分钟最多回 `per_minute` 次（默认 6）。
5. 几条规则同时对上时只回一条，优先级依次是：比法越精确越先、本群专用的先于所有群共用的、触发词长的先于短的。

冷却期间对上的消息不算已处理，照常交给后面的插件（例如群聊搭话）。

拿不准会不会误触时，用控制台的「试一句」，或在群里发「自动回复 试 一句话」：能看到这句会不会触发、由哪条规则回，没触发时也会说明原因（比如超过字数上限、要 @ 才回）。

## 群里的指令

群主和群管理员能用，机器人管理员（`ctl.admins`）也能用。把 `managers` 改成 `admin`，就只剩机器人管理员能用。规则编号用「自动回复 列表」查看。

| 指令 | 作用 |
| --- | --- |
| `自动回复` / `自动回复 列表 [页码]` | 本群看得到的规则（本群专用的 + 所有群共用的），带编号 |
| `自动回复 添加 <触发词> <回复>` | 只在本群回。几个触发词用 `\|` 隔开；回复可以多行、可以带图。触发词与比法都相同的规则已经存在时，这句会作为它的新说法加进去 |
| 引用一条消息，再发 `自动回复 添加 <触发词>` | 把那条消息存成回复：文字原样保留，图片下载到本机，表情也会保留。引用的是合并转发时，整条展开存下 |
| `自动回复 加说法 <编号> <回复>` / `改 <编号> <回复>` | 再加一种说法 / 换掉全部回复（同样可以引用消息） |
| `自动回复 加词` / `删词 <编号> <触发词…>` | 增删触发词 |
| `自动回复 模式 <编号> 精确\|包含\|开头\|正则` | 改比法 |
| `自动回复 转发` / `艾特 <编号> [开\|关]` | 折成合并转发发出 / 只在 @ 机器人时回 |
| `自动回复 冷却 <编号> <秒\|默认>` | 这条规则自己的冷却 |
| `自动回复 停用` / `启用 <编号>` | 群管理员停用所有群共用的规则时，只在本群生效 |
| `自动回复 删除 <编号…>` / `恢复 [编号]` | 删除的规则进回收站（保留最近 20 条），可以找回 |
| `自动回复 看 <编号>` | 显示详情，并把回复实际发一遍 |
| `自动回复 试 <一句话>` | 看这句会不会触发、由哪条规则回 |
| `自动回复 全局添加 <触发词> <回复>` | 所有群共用（仅机器人管理员） |
| `问答` | 所有人可用：列出本群能问的触发词（`menu = false` 可关闭） |

在群里加的规则只管这个群。所有群共用的规则只有机器人管理员能加、改、删。号主私聊机器人用同一套指令时，管理的就是所有群共用的规则。
