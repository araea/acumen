# 架构与图片渲染审计

## 结论

保留 Rust / Tokio、Satori、SQLite 与静态插件注册表。注册表是帮助、控制与插件生命周期的共同来源，网页卡片已有统一出图入口。问题集中在任务资源管理与排版边界，不需要整体重写。

## 已修正的问题

| 发现 | 改进 |
| --- | --- |
| 统计图、GIF 信息和拆帧仍同步占用 Tokio 工作线程，其他图片任务直接进入无统一上限的阻塞池 | 统计、词云、GIF、切分统一经过两槽工作池；执行槽由阻塞闭包持有，取消调用方不会突破并发上限 |
| 消息等待 future 被取消后，注册项可能残留；恰好关闭的接收者会吞掉事件 | RAII 注销，发送失败保留原事件并继续匹配 |
| 截图主动关闭过程被取消时，标签页所有权已经取走 | await 完成前保留守卫所有权，取消后仍可清理 |
| 浏览器预热没有启动总时限 | 15 秒超时后继续启动，卡片沿用文本回退 |
| 词云 PNG 编码后又解码、扫描每个像素、裁切、重新编码 | 保留固定画布，一次编码；减少中间图像和像素扫描 |
| GIF 超大缩放、网格、帧数及 NaN 参数缺少护栏 | 256 帧 / 3200 万总像素限制，输出分配前校验尺寸和有限正数 |
| 图片切分向下取整，遗漏右边与底边像素 | 相邻网格边界差分，余数分散到切片；7×5 图片切成 3×2 后能逐像素复原 |
| 稀疏走势图的时间轴按各系列首次出现顺序拼接 | 合并排序；更均匀的纵轴刻度，避免小数刻度取整后重复 |
| Cargo.lock 未纳入版本控制，文档宣称 Rust 1.85 即可构建 | 提交当前通过验证的锁文件，使用 `--locked`；锁定依赖中 SQLx 要求 Rust 1.94，同步最低版本说明 |

两槽工作池限制同时计算的数量，不限制等待中的请求总数。Satori 事件仍异步派发；本次未更改业务消息队列和定时推送策略，也没有把单机测试包装成生产吞吐量基准。外部接口延迟与 QQ 客户端图片压缩不由排版层控制。

## 阅读效果

| 内容 | 调整 |
| --- | --- |
| 帮助、控制 | 标题与状态固定对齐，配置键另起次要一行，避免长键挤压中文名称 |
| AI 资讯、热点、日报、模型榜 | 保留日夜主题，柔化装饰背景，取消标题和正文的 CSS 行数裁切；摘要仍受配置字符预算约束 |
| 用户画像 | 标签 19px、证据 17px，提高次要文字对比度，调整综述行高；保留事实、统计、推断的区分 |
| 智能回复 | 正文 17px，标题层级更清楚，代码块完整换行，表格不再依赖横向滚动，来源标题完整显示 |
| 发言排行榜 | 保留彩色横条、条内姓名（放不下即截断）与紧跟条尾的次数/占比；色带四角圆润，实色条与轨道交界处平切；刻度竖线沿用原来的等距密度，只刻在色带里、收在圆角之前，默认由实色条盖住（`ranking_grid_over_bars`），文字始终在最上层；标题在最上、时间与范围并成一行小字跟随；头像加发丝细描边；每行的条、轨道、数值、占比取自同一支色相的四个调子（头像色先收进固定的饱和度/明度窄带，中性色不染色相），底淡字深，二十行是二十套同构配色；纸面暖白 |
| 消息类型与走势 | 保持同类颜色一致，降低饱和度、弱化网格，稀疏时间序列按日期对齐；与排行榜同一套标题层级与暖白纸面，占比一律取整（不足半个百分点写 `<1%`） |
| 词云 | 暖白背景、横向排词、低饱和配色，保留留白与稳定画布比例 |
| GIF、切分、媒体、网页截图 | 保留来源内容与原有用途；改善计算调度、尺寸保护和边缘完整性 |

资讯、画像固定 720 CSS px，避免浏览器滚动条把版心压成 705px。网页出图同时等待字体与内嵌图片解码（沿用 900ms 上限）。智能回复卡片加上 CSP，禁止脚本与外部图片加载。本地可信 HTML 清单仍能正常排版。

## 验证与复现

```sh
cargo test --locked
cargo build --release --locked
node tests/foreground.cjs
node tests/restart.cjs
bash scripts/review-cards.sh
```

`review-cards.sh` 只使用合成数据与本地 Chromium，生成帮助 4 张、控制 5 张、资讯 5 张、画像 3 张、智能回复 2 张网页样张，以及 4 张统计图（含 20 人规模的排行榜样张）与词云。`tests/cards.cjs` 检查出图宽度、横向溢出、高度、脚本拦截、长配置值换行，输出 `layout-audit.json` 与可浏览的 `index.html`。图像的审美仍需实际看图，自动断言只负责结构与内容边界。

生产截图路径另有 ignored 测试，可独立执行：

```sh
cargo test --locked captures_complete_cards -- --ignored --test-threads=1
cargo test --locked renders_a_complete_card -- --ignored --test-threads=1
cargo test --locked oversized_card_fails_without_breaking_the_next_capture -- --ignored --test-threads=1
```
