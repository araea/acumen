# 统一设计系统升级记录

基线：`1ff3107`。日期：2026-09-25。范围：主框架与全部 22 个注册插件。

视觉以 Material 3 Expressive 为唯一来源；Apple HIG 仅约束平台交互。WCAG 2.2 AA 为验收目标，自动检查不构成无障碍认证。

| 审计问题 | 实现结果 |
| --- | --- |
| 信息图片缺少等价文本 | 帮助、控制、OAI、资讯信息卡附完整文本；统计图附数据列表，词云附词频；图片摘要注明文字入口。 |
| 卡片弱化文本对比度不足 | 卡片与控制台采用同一 HCT 角色，弱化文字统一映射 on-surface-variant；分隔文字也满足文本阈值。 |
| 保存竞态及虚假成功 | 配置字段连续编辑串行保存；内容编辑保留请求期间的新草稿；OAI 原子保存失败恢复内存并报告。 |
| 全局群名单说明与实现矛盾 | 界面和配置文档明确启用空白名单禁止全部群、白名单优先；保留线上实际过滤行为。 |
| OAI 删除和清空不可恢复 | 操作者须在同一会话中 60 秒内重发确认；确认绑定命令和数据版本，展示影响范围。 |
| 注册表指令与真实语法不符 | 更正对话、停止、复制、重命名和历史清空说明；控制台复制单一模板并补真实词指令前缀。 |
| 走势图仅依赖颜色 | 每个系列拥有图例与数据点编号，附完整文字数据；超过五个系列不再只能通过重复颜色辨认。 |
| 设计令牌存在多份手工副本 | 单一生成器产出控制台颜色、卡片令牌和 Rust 原生色表；字阶、形状、角色、字体共享，卡片仅保留明确的输出尺度映射。 |
| 模型 HTML 可覆盖卡片外观 | Markdown 中的原始 HTML 转义；智能体和模型列表使用 Markdown，同一内容可直接用作文本。 |
| 刷新和保存导致草稿、焦点丢失 | 保留未保存表单节点和焦点；保存其他表单不丢输入；删除连接重排标识；离开未保存内容有保护。 |
| 配置缺乏字段说明、数组转换有损 | 使用配置参考的字段说明、后端选项约束；数组用 JSON 保留元素类型并支持对象增删；拒绝误存隐藏凭据占位符。 |
| 生命周期文案互相矛盾 | 帮助与控制统一说明首次启用自动初始化、连接和排期变更在下次连接生效。 |
| OAI 文本降级暴露 HTML、来源丢失 | 内置清单共用 Markdown；完整 URL 同时进入卡片和文本；文本保留模型、工具回执。 |
| 条形图长度不与数值成比例 | 移除最小实色条长，零值不画条；名称独占一行，小值也能辨认。 |
| 主动指令失败静默 | 头衔权限、撤回失败或未引用、切图无效参数均有操作结果与下一步提示。 |
| 测试夹具未覆盖真实插件 | 浏览器测试从 Rust 注册表导出全部插件的真实默认配置；后端隔离测试逐个核对 API；卡片测试强制全部族存在并检查计算颜色。 |

补充：表情画廊默认显示第一帧，原图需主动播放且可停止；错误提示不再按十秒自动关闭；Cookie 加入统一敏感字段脱敏。

## 验证

- `python scripts/make-tokens.py --check`：核对所有生成物与唯一来源一致。
- `cargo test --locked`：解析、状态、持久化失败回滚、确认范围、渲染结构、图表和全部插件兼容性。
- `node tests/console-state.cjs`：复现连续编辑、保存期间的新草稿以及 JSON 数组往返。
- `node tests/console.cjs`：真实 Chromium，包含通用交互、所有 22 个插件的真实配置、320px 回流、200% 字号、键盘焦点、强制颜色与减少动态。
- `scripts/review-cards.sh`：所有卡片族与原生统计/词云样张；检查溢出、文本对比度与截图边界。
- `cargo build --release --locked`、`node tests/console-backend.cjs`：构建发布产物，以无 Satori 适配器的隔离进程检查 API 与内嵌资源。

上线使用既有 runit 服务，保留上一版可执行文件并在停机后备份配置和数据；不修改生产配置。启动后只读核对进程、控制台和连接状态。VoiceOver、TalkBack、实际 QQ 客户端和 iOS 安全区仍需要有相应设备的人工验收。

本次发布前结果：582 项 Rust 测试通过，39 项外部依赖或样张测试按需运行；卡片流程另完成 16 张 HTML 卡片及原生统计、词云样张检查。浏览器通过 62 个界面快照和全部 22 个真实插件配置检查，隔离 release 后端通过全部插件 API 与内嵌资源字节一致性检查。保存竞态、离页保存和类型往返专项回归通过。
