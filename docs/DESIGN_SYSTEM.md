# 知微统一设计系统 · Material 3 Expressive

适用于主框架、控制台以及全部注册插件的视觉、交互、信息内容与文案。旧版混合视觉体系（包括 squircle 与另一套字阶、间距来源）已废弃；不借其它设计系统的颜色、组件或装饰。

实现入口：`res/console/tokens.css`（共享基础令牌）、`app.css`（组件与响应式布局）、`app.js`（状态与交互）、`index.html`（语义外壳）。

## 原则与裁决

视觉只用 Material 3 Expressive（M3E）：HCT 动态角色色、表面层级、15 级字阶、形状级、状态层、空间 / 效果动效、底部导航 / 导航轨、分段列表与控制组件。Apple HIG 仅用于平台交互体验：系统字体、安全区、系统深浅 / 增强对比 / 减少动态偏好、iOS 输入防缩放、系统选择器与原生对话框。不使用 iOS 风格控件或其它视觉体系。

发生冲突时，**平台惯例、可用性与无障碍优先于视觉一致性**；始终以 WCAG 2.2 AA 为下限。

**2026-10-19 重做**：整套界面推翻重画——浮动导航坞、填充式输入框、新的「缺一角的环 + 一点光」应用图标。2026-10-18 那一轮的 Material Symbols 图标仍保留。

**2026-10-22 柔和默认（当前版本）**：**阅读舒适是第一原则**，配色向它让路。默认方案从 Fidelity 换成 Tonal Spot（主色彩度 55 → 32，正文 on-surface 落在 T21 而不是近黑）；运行卡与日志台不再是两块固定的深色，改为随明暗走的色调面；深色模式不用近黑底；说明文字 13.5 → 14px。**下文凡与此冲突的旧说法以这一段为准。**

## Tokens

- `scripts/make-tokens.py` 根据靛青种子 `#3f51b5`、Material Color Utilities 的 2025 Tonal Spot 生成浅色、深色及各自增强对比的 `--md-sys-color-*`。不要手改生成块。`success`、`warning` 是 harmonize 后按相同方案生成的自定义角色，信息还必须带文字。在算法之上只有两处为眼睛做的取舍（`make-tokens.py` 与 `scripts/theme/engine.mjs` 同一张表）：**深色表面族**在标准对比度下改取中性调色板 T4–T24（页面 T6、容器 T10 / 12 / 17 / 22，即 M3 基线深色那一档）——2025 规范的深色页面是 T4、最低一层是纯黑，浅字压在近黑上会起光晕、在 OLED 上拖影；增强对比度时照算法来。**界面专属色**（运行卡、日志台、光点、选中行文字）也从同一方案的调色板里取，见下条。
- **卡片的令牌已冻结**：`res/cards/tokens.css` 自 2026-10-19 起不再由这个脚本覆盖（卡片要按群聊缩略图的 20px 根字号与旧字阶出图）；脚本只继续生成控制台令牌与 `src/render/tokens.rs`。要改卡片直接改那一份。
- `--md-sys-typescale-*`、`--md-sys-shape-*`、`--md-sys-motion-*`、`--md-sys-state-*`、`--md-sys-elevation-*` 是视觉令牌；`--zw-*` 只放产品几何映射（4dp 间距基线、尺寸、安全区、焦点环）。组件层不另造全局令牌，不硬编码颜色 / 形状 / 字号。
- 同一脚本仍生成 `src/render/tokens.rs`（原生统计图与词云不得手抄配色）；`res/cards/tokens.css` 已冻结（见上）。卡片根字号 20px，用同一 rem 字阶适配群聊缩略图，空间间距按 4px 基线映射；卡片的语义角色与控制台一致。
- 颜色配对成套使用：`primary/on-primary` 主操作；`secondary-container/on-secondary-container` 导航选中与次级块；`primary-container/on-primary-container` 用于选中行（文字取 `--zw-selected-fg`，见下）；`tertiary-container/on-tertiary-container` 插件总数强调；`surface-container-*` 其余表面。运行卡、日志台与暖色光点是界面专属的 `--zw-*` 颜色（`--zw-hero-*`、`--zw-log-*`、`--zw-accent`），也在生成段里、**随明暗走**：运行卡浅色取主色调色板 T92 → 色相偏 18° 的 T86，字 T10 / T30，主按钮 T40；深色 T22 → T30，字 T95 / T82，主按钮 T86。日志台浅色是中性 T95 底、T15 字、T38 次要字；深色 T10 底、T88 / T70。增强对比度时次要字再拉开一档。`outline` 用于需要 3:1 的控件边界，`outline-variant` 仅用于装饰线；文字不使用 `outline`。
- 字体使用系统无衬线，日志 / 代码使用系统等宽，数据用 `tabular-nums`。字号用 rem，输入框不得小于 16px。圆角使用 M3E shape scale（卡片 28、运行卡 32、列表行 20），不启用 squircle 或其它形状体系。**读起来舒服是第一位的**：正文 15px / 25px（行高 1.5625，中文长段不挤）、说明 14px / 23px（配置说明、列表副标题是全界面读得最多的字，不再比正文小一档半）；标题与强调取 700（`--zw-weight-heading`），display 取 800，字距收紧到 `-0.02em`——这是 M3E 的 expressive 档。
- **聊天卡片的字体与控制台不同**：卡片在服务端出图，读者的平台字体用不上，而 `system-ui` 在出图机上会落到 DejaVu Sans（拉丁字母又宽又散，汉字另走只有 Regular 一档的思源黑体，500 / 600 字重出不来）。所以 `scripts/make-tokens.py` 在卡片令牌里把 MiSans 排在最前——汉字拉丁一体、字重 Thin–Heavy 齐全；没装它的机器照旧走控制台那一串。装在 `$PREFIX/share/fonts/TTF/MiSans`，属设备本地状态。
- 颜色反馈使用状态层（hover 8%，focus / pressed 10%）；位置与尺寸用 spatial fast / default（350 / 500ms），透明度 / 颜色用 effects（150 / 200 / 300ms）。减少动态时空间动画归零、循环动画停用。阴影仅用于浮层，内容卡片以容器色分层。

## 布局

| 视口 | 导航 | 内容 |
| --- | --- | --- |
| <600px（compact） | 68px 浮动导航坞（离底 12px）+ 安全区；当前页展开成实心药丸 | 顶栏 64px（品牌、刷新）；16px 页边距；层级详情独立页 |
| 600–839px（medium） | 96px 导航轨，通到窗口顶端，品牌图标住在轨顶 | 顶栏只剩右栏（滚出后的页名、刷新）；24px 页边距 |
| 840–1199px（expanded） | 264px 展开轨，轨顶是图标加名字 | 插件列表与详情并排；总览单列通栏 |
| ≥1200px（large） | 同上 | 32px 页边距、1180px 最大宽；读数一行四格 |

**导航轨从窗口顶端通到底**（≥600px）：品牌是顶栏里的那个链接，用 `position: fixed` 落在轨顶，顶栏随之只占内容那一栏——大屏上不再有一条横贯整页、几乎空着的栏。解锁页没有导航轨，品牌回到顶栏原位。

总览按运行卡 → 连接 → 读数 → 最近日志组织；手机与桌面都按这个顺序纵排，读数在 ≥1000px 时才排成一行四格。插件详情在宽屏独立滚动，窄屏可返回列表。**详情的顺序是开关 → 指令 → 现在的情况 → 配置 → 与默认值的差异**：配置往往很长，指令不能压在末尾让人滚。大标题在正文，滚出后顶栏接管。任何断点均不得出现页面横向滚动。

**页面上没有大块的反色面**：浅色模式里运行卡是一张淡淡的主色调卡片、日志台是一张浅灰纸，深色模式里两者才是深底——眼睛不必在一屏里来回适应两种亮度。运行卡靠色相、大字与装饰环当锚点，不靠一块黑。四格读数是四张独立的圆角卡，每格带一枚圆形图标；「已启用插件」靠图标底（tertiary-container）与 `<meter>` 占比条带一点第三色。日志台用 `--zw-log-*` 固定深色，与纸面正文分开。

## 外观（主题配置）

「设置 › 外观」（`#/settings/appearance`，`app.js` §11c）让人换掉默认的靛青。它只改控制台，**聊天卡片不跟着变**（卡片令牌已冻结，见上）。

- **主题色**：九枚预设色板 + 「自选」（系统取色器）+ 「从图片取色」。色板学安卓「壁纸与个性化」：一枚圆盘切成主色 / 次色容器 / 第三色三块，选中时圆盘变成圆角方（M3E 用形状变化表达选中）、外圈主色描边、中间对勾。取色走 Material Color Utilities 的 Celebi 量化 + Score（与安卓壁纸取色同一套），图先缩到 128px，取前四种做候选，第一种直接换上。
- **配色风格**：柔和（Tonal Spot，默认）/ 原色（Fidelity）/ 鲜明（Vibrant）/ 跳色（Expressive）/ 素雅（Neutral）/ 黑白（Monochrome）。每张单选卡左侧是这个种子在该方案下的三色小样，换种子时小样跟着重算。
- **明暗**（跟随系统 / 浅色 / 深色）、**对比度**（跟随系统 / 标准 / 中 / 高，对应 contrast level 0 / 0.5 / 1；跟随系统时「增强对比度」取 0.5）、**字号**（小 / 标准 / 大 / 特大 = 根字号 93.75%–125%，全界面是 rem，所以整页按比例放大）。分段按钮铺满一行，窄于 380px 时去掉图标。
- **改了立刻生效，没有「保存」**：这是偏好，不是配置（HIG 的设置页惯例）。成功不出提示条——页面本身变了就是回执；只有同步失败才报。「恢复默认外观」一键回到出厂。
- **实现**：`res/console/theme.js` 是 `scripts/make-theme.sh` 用 esbuild 把 `scripts/theme/engine.mjs` 与 `@material/material-color-utilities@0.4.0`（2025 规范）打成的 IIFE，**只在外观页与主题需要重算时才加载**。它输出一张 `:root:root` 选择器的覆盖样式（比 tokens.css 的 `:root` 高一档，媒体查询里的也压得住），结构与 tokens.css 的生成段相同（浅 / 深 / 各自的增强对比度），运行卡、日志台、光点与 `--zw-selected-fg` 与生成段同一张色调表，所以换了种子它们也跟着色相走。默认种子 + 柔和方案下引擎与 `make-tokens.py` 的结果逐项相同（四套都核）。
- **首帧不闪**：算好的 CSS 连同选择与引擎版本（`THEME_ENGINE`）记在 `localStorage["acumen.theme"]`；取色表改过就把版本加一，首帧不贴旧版本算的缓存，登录后按原来的选择重算。`index.html` 头部一小段内联脚本在样式表之后、`app.js` 之前把它贴回去，同时改 `theme-color` 与 `color-scheme`。全是默认值时什么都不注入。
- **跨设备**：种子、方案、明暗、对比度存在 `data/console/theme.json`（`GET/POST /api/theme`，只认白名单里的值），登录后对一次，别的设备改过就跟上；字号只属于这台设备。

## 图标

图标是 **Material Symbols Rounded**（字重 400、光学尺寸 24、GRAD 0）——M3E 配套的那一套，不再手绘。`scripts/make-icons.py` 从 `@material-symbols/svg-400` 取出用到的字形，写进 `index.html` 里一段 `@generated` 的内联精灵图；`app.js` 的 `icon()` 按名字取出 symbol 的路径，**抄进每一枚 `<svg>`**，不用 `<use href="#名字">`——不少手机自带浏览器与 App 内置浏览器画不出 `<use>` 引用的 symbol，整排图标空白。内联而非外部文件，首帧就有图标，也不多一条静态路由。用 `mask` 着色的品牌标记一类同时写 `-webkit-mask`（Chromium 120 以前只认带前缀的）。许可证见 THIRD_PARTY_NOTICES.md。

- **一个概念一个图标，全界面同一个。** 导航的「搭话」是 `forum`，插件「群聊搭话」也是；导航的「日志」是 `receipt_long`，插件「日志输出」也是。旧版二十五个插件只有四五种图标（五个系统插件共用一个「设置」滑块，与导航里的「设置」撞车），列表里的图标等于噪音；现在**每个插件一个自己的字形**（`app.js` 的 `PLUGIN_ICONS`），新插件没登记时按分类兜底。
- **字形是名字，色调是类别。** 插件的图标方块（`.tile`）按分类着色：消息 · 媒体取主色、互动 · 娱乐取第三色、统计 · 资讯取成功色、系统取中性色，底色是色调角色按 20% 调进容器色里（浅色是淡淡一抹、深色是暗暗一抹，不会像整块容器色那样在深色里亮成一片）。选中的行方块换实心主色。
- **选中用实心，其余空心。** 导航与状态符号成对给出 `名字` 与 `名字-fill`：导航的当前页、名单「现在的效果」里的对勾 / 警示 / 信息、字段错误与危险确认框顶上的警示都用实心版。导航的两枚图标同时在 DOM 里，由 CSS 按 `aria-current` 显示其一，换页不必重画。
- 图标只是装饰：一律 `aria-hidden`，名字由旁边的文字或按钮的 `aria-label` 负责；纯图标按钮必须有 `aria-label`。
- 新增图标：把名字加进 `scripts/make-icons.py` 的 `INVENTORY`（名字后带 `+` 同时要实心版），运行脚本；缺字形会直接报错，不会悄悄漏掉。`--check` 校验 `index.html` 里的产物是最新的。
- **品牌标记**是应用图标里那枚「缺了一角的印」，用蒙版着色（`.brand-mark`、解锁页、空状态），所以随主色、明暗与对比度一起变。应用图标本身（`icon.svg`、`icon-monochrome.svg` 与四张位图，`scripts/make-icon.py`）是一个圆角方环在右上留出缺口，缺口里嵌一粒暖色光点：环是看见的整体，光点是被看见的细处。几何全部落在自适应图标的安全圆（半径 33/108）内；16px 下环宽约 1.7 个设备像素、光点约 1.8 像素。旧版的七瓣曲奇已删除。

## 组件与交互契约

- **导航**：五个真实链接；当前页 `aria-current="page"`。路由更新文档标题，切页焦点进入 h1，前进 / 后退有效。胶囊是独立的绝对定位层（`.nav-pill`），由 `app.js` 的 `paintNavPill` 逐帧跟随当前格：换页时旧胶囊滑到新格，当前格的宽度由 flex 过渡伸展；用 `secondary-container` 而不是主色，滑过其他图标时它们仍是深色，不会出现「白图标压在浅底上」的一瞬。首帧、断点与减少动态直接落位。紧凑底栏还支持**长按拖选**：按住 200ms（或横移 8px）后五格摊成等宽，胶囊跟手连续移动，松手落在最近一格并展开；短按、键盘与桌面导航轨保持原样。拖选期间标签隐藏，避免字被手指和胶囊挤在一起。
- **液态玻璃（2026-10-21，用户点名要的例外）**：视觉体系仍是 M3E，玻璃只是**运动中的材质**——紧凑底栏的胶囊在点按换页的滑行、长按拖选的跟手时化成一枚浮起的透镜：升到图标之上、`secondary-container` 调到 34% 透明并加饱和，`index.html` 的 `#zw-glass`（`feDisplacementMap`，中间平、边缘折）把底下的图标折一折，`::after` 画一道跟着手指走的高光与内描边；形变按速度横向拉长、纵向收（体积约守恒，用独立的 `scale` 属性，不碰 JS 写进 `transform` 的位移），落格时回弹一下再凝回实心药丸。静止状态一律是原来的实心药丸，导航轨上下换格不出现玻璃。`backdrop-filter: url()` 只有 Chromium 认，别处退回半透明加模糊；`prefers-reduced-motion` 时没有这一层（动画本来就归零），`prefers-reduced-transparency` 与增强对比度时只留形变不透明，强制颜色模式下不画高光。
- **按钮 / 开关 / 筛选**：filled > tonal > outlined > text；开关为 52×32 M3 轨道、`role="switch"` 与 `aria-checked`，名字不随状态变，打开时滑块变大并镂出一枚对勾（蒙版相减，颜色就是轨道色）；筛选芯片使用 `aria-pressed`，选中有形状 / 勾选标记而非只变颜色。`aria-checked`、`aria-pressed`、`aria-selected` 一律写成 `"true"` / `"false"`，不留空串（`h``` 会把 `false` 渲染成空，空串等于没写，读屏读不出「关」）。触屏目标 ≥48px，精确指针 ≥40px。
- **列表 / 编辑**：每一行是独立小卡（20px 圆角、行间 4px），整行链接与尾部开关是两个独立命中目标；输入框是填充式（`surface-container-high`，圆角 20，聚焦换成主色描边），标签保持可见，错误在本字段下说明并以 `aria-invalid`、`aria-describedby` 关联。
- **插件列表**：按分类分块，每块一个小标题（名字 + 个数），块内是一摞独立小卡（每行 20px 圆角、行间 4px 缝）；每行左侧一块 46px 的图标方块（见「图标」），右侧只有开关——整行是进入详情的链接，不再加一枚箭头去占说明的宽度。筛选条在窄屏上一行横向滑动，不折成两三行吃掉首屏。选中行换 primary-container、文字取 `--zw-selected-fg`（= on-primary-container：浅色是淡底深字，深色是暗底浅字），方块换实心主色；说明在列表里最多两行，完整内容在详情里。详情页头是 56px 的图标方块 + 名字 + 代号 + 状态。
- **配置表单**：一层配置 = 一块分段列表（2026-10-21 起再加：总开关打头、「已改」与行内恢复默认、筛选、映射表增删、列表编辑器，见下面几条），每项是一格「设置行」（`.setting`，色调底、行间 2px 缝、块两端大圆角）。顶层的叶子收进「常规」，每张子表另起一块；同一层里叶子在前、子表在后，分段列表不会被子表从中间隔开。**键与说明各占一行**：键是 `<label>`，说明是 `.field-hint` 并挂在控件的 `aria-describedby` 上，不混进控件的名字（旧版把说明塞在 label 里，读屏会把整段说明当名字读，视觉上也和键连成一行）。数字与下拉的行在表单容器 ≥38rem 时改成「左说明、右控件」（`@container`，看表单自己的宽度而不是视口：宽屏的详情栏只有半边，手机上则占满），文本、列表、多行文本与名单始终上下叠放，因为它们的值与说明都长。说明用 body-medium（14px），不再是 12px 的 body-small。
- **名单编辑器**（全局黑白名单、各插件 `channel.white / black`，以及 `groups`、`management_groups` 等群号列表；私聊对象名单 `private_users`、`realtime_muted_private_users`、`ctl.admins` 也是同一个组件，只是名册换成好友、措辞换成「账号」）：名单是一组已选的群或人，名字为主、ID 为辅（群名来自 `/api/groups`，即实现端的 `guild.list`；好友来自 `/api/friends`，即 `friend.list`，名字与昵称 / 备注都能搜；读不到时只显示 ID，输入照常可用）；加人加群有三条路——输入或整段粘贴（逗号、顿号、空白、换行、带引号的 JSON、全角数字都能认）、输入群名自动打开选群面板、点「从已加入的群里选」。选群面板窄屏是全屏对话框、宽屏居中；已选的排最前，搜索群名或群号，**完成才生效**，取消 / Esc 不改任何东西，名单里有而名册里没有的（已退群的群、不是好友的账号）也能取消勾选。移除键是独立的 48px 命中区，移除后焦点交给顶上来的那一行，提示条带「撤销」。底下一句话说明名单**现在的真实效果**（白名单开着就不查黑名单、空白名单禁止所有群……），图标区分语气，不只靠颜色。保存口径不变：插件里的名单每次改动立刻写入、连着改合并成一次补写、失败退回原样并在输入框下说明；全局名单是草稿，随「保存全局设置」一起写入，算「未保存」。ID 只校验「像不像一个 ID」，不限数字（微信群是 `…@chatroom`，微信账号是 `wxid_…`）。
- **列表编辑器**（2026-10-21，`app.js` §11b）：不是 ID 的列表——指令前缀、别名、关键词、模型关键字、提醒秒数、时间点、星期——每一项是一枚 M3 输入芯片（40 高、上下借行缝凑满 48 触控区，中等圆角，`surface-container-highest`）。芯片本体是「修改」按钮：点一下，值进到下面的输入框里改（芯片描主色边标出「正在改」，按钮换成「保存」，Esc / ✕ 取消，改成空就是删除）；尾部 ✕ 是独立命中区，移除后焦点交给顶上来的那一枚的 ✕，提示条带「撤销」。顺序：鼠标按下拖动、触屏按住 320ms 再拖（之前一动就让给页面滚动），芯片跟手浮起，经过别的芯片就换位，松手写入；键盘 Alt+方向键移动、方向键在芯片间走、Delete / 退格移除；空输入框里退格先跳到最后一枚，不直接删。添加：回车或「添加」；文字列表粘贴多行按行拆开，数字列表认空格 / 逗号分隔的一串；重复的不加，闪一下已有的那一枚。时间点列表用 `type="time"`（系统选择器，HIG）并按先后自动排序，不给拖动；`weekdays`（1–7）是七枚开关芯片。用法说明只在编辑器有焦点时显示（仍挂在 `aria-describedby` 上）。写入口径与名单编辑器同一个 `saveList`：插件里立刻落盘、连着改合并成一次补写、失败退回并在输入框下说明；设置页的指令前缀是草稿，随「保存全局设置」一起写。对象列表、混着类型或带已隐藏凭据的列表仍是多行 JSON。
- **配图（本机图库）**（2026-10-22）：`images` 这类图片列表换成图库编辑器——一格方图一张（`auto-fill` 分列，窄屏两列），点开是原图预览（原生 dialog 管 Esc 与焦点，关掉后焦点回到那一格），右上角一枚 32px 的圆是移除键、四周借 8px 凑满 48 触控区，移除走与列表编辑器同一个 `saveList`（立即落盘、可撤销）。下方「从相册选择」交给系统文件选择器（`accept="image/*"`、多选，HIG：平台自己那一套），选完逐张上传——按钮上写「正在上传 2/3…」、进度走 `status`，全部到齐后一次写进列表；「粘贴链接」展开一个直链输入框，口径仍是列表编辑器那一套。空状态是一块虚线框，说明「还没有配图」，图片没加载出来时露出的是那枚占位图标。图片由 `/api/plugins/<插件>/asset` 收、`?w=` 出缩略图（`.thumbs/` 缓存），列表里存的是 `data/welcome/` 下的文件名；绝对路径与直链不经过图库。
- **映射表**（键由人定的表：`welcome.groups`、`ai_news.group_preferences`、`oai.providers`、`oai.search.backends`）：后端 `maps()` 说明每张表的键是群号、推送目标还是自取的名字，以及新的一项的模板与字段说明。每一项是一块可展开的分段卡（复用记忆卡的 `details`），标题是群名 / 好友名 / 名字，展开状态在重画后保留。添加：群与私聊对象走选群面板，名字走起名对话框（建议名芯片、字母数字下划线连字符、重名就地报错）；新加的覆盖项**照抄上层的当前设置**，行为不变，改哪项才是单独定。覆盖项里的字段可以「沿用上层」（删掉这个字段），没写的字段列成「+ 字段名」芯片随时补回。删除整项要确认；带已设密钥的项明说删了只能重填。增删走 `config/insert`、`config/remove`，只对映射表开放（`表.键` 或可选覆盖的 `表.键.字段`），写入照常经 `ctl::change` 校验。
- **文案编辑器**（2026-10-22，`app.js`「文案编辑器」节，后端 `templates`）：带占位符的提示字段不再当芯片列表或大文本框画。每种说法一块 `surface-container` 小卡：「说法 N」+ 删除，填充式输入框随内容长高（`field-sizing: content`，最多 12 行），下面是预览——左侧一枚 32px 圆头像、右侧气泡（`surface-bright` 底、贴头像那一角收成 extra-small，深色里不落到近黑）。样例值点线下划、`{甲|乙}` 虚线、`@` 用主色、配图 / 头像 / 表情是次色容器小块；认不出或这一种提示里用不了的占位符标成 error-container 并在框下用文字说明（不只靠颜色）。底下一行「插入」芯片：窄屏横向滑动、编辑器宽过 30rem 就换行铺开；点芯片插在最后编辑的那一种说法的光标处，`mousedown` 不抢焦点（手机键盘不收起），随机片段插入后选中示例文字。焦点离开整个编辑器才保存（在说法之间、芯片之间移动不算），Ctrl / ⌘ + Enter 立即保存；删一种说法给「撤销」。全部删掉 = 这条提示不发，编辑器里明说。
- **字段的中文名、先后与依赖**：后端可给 `labels`（`路径` 或映射表里的 `表.*.字段` → 中文名）、`option_labels`（下拉框每个取值的说法）、`depends`（只在某项取某些值时才用得到）；`field_order` 从配置参考按出现先后生成，所有插件的表单都按它排。有中文名时名字在前、键名作 label-medium 小字跟在后面（`/ctl` 仍认键名），说明开头重复名字的「名字：」剪掉；用不到的项不压暗（会掉到 AA 以下），只在说明下加一行主色 info 图标的话。键名以 `_seconds` 结尾的数字框旁边实时换算成「5 分钟」。
- **与默认值比较**：每一格设置行和默认值比，改过的在键名旁标「已改」（次色容器小牌），文本 / 数字 / 列表另有一枚「恢复默认」（`settings_backup_restore`，名字里带默认值），只重置这一项（`ctl reset 插件 路径`）；开关不给这枚按钮——再点一下就是恢复。凭据、映射表里的字段不比。
- **总开关**：一节里布尔的 `enabled` 排到最前、标「总开关」，开着时整行换次色容器；关着时下面一句「这一节的其余设置暂不生效；可以先改好再打开」，其余项照常可改，不藏起来。设置行里点键名或说明等于点它的开关（整行是命中区，HIG），选中文字时不触发。
- **配置筛选**：叶子 ≥12 项的插件在配置上方给一个筛选框，键名与说明都认；命中的行留下，小节名命中时整节留下，落在折起来的映射项里的会把它展开（清空后再收起）；结果数走 `status`。
- **凭据字段**（键名含 token / secret / password / api_key……，与后端 `ctl::sensitive` 同一张词表）：密码框、永远空着，占位写「已设置（不显示）；输入新值即替换」或「未设置」，带显示 / 隐藏；只有亲手输入（`typed`）的非空值才提交。后端 `redacted` 不再把空密钥显示成已隐藏，界面才分得出设没设。
- **新版本**：顶栏右侧一枚 `tertiary-container` 药丸「更新」，只在有新版本时出现，所以全界面只放这一处（总览不再另放一颗）；点开是确认框，说明正文放在可滚动的 `.dialog-notes` 里。
- **停机页**（经管理面板打开、知微没在运行）：总览的运行卡换成中性的 `surface-container-highest` 渐变（`.hero[data-offline]`），状态牌「已停止 / 无响应」，主按钮「启动」用主色；起停与更新的进度是 `.job`（波浪进度 + 深色输出块），失败时整块以 `alert` 播报。其余页面在停机时也显示这一屏，不出报错页。
- **页签 / 对话框 / 提示**：页签支持方向键、Home、End；原生 dialog 初始焦点在取消，Esc 返回触发者；提示可关闭，悬停 / 聚焦暂停倒计时，错误提示保留至关闭或后续反馈；成功走 `status`，失败走 `alert`。
- **加载进度**：M3E 的波浪线性进度（`.progress`），整条波形缓缓流动，形状用蒙版、颜色取主色；减少动态时静止。
- **日志**：随明暗走的日志台（`--zw-log-*`，浅色里是浅灰纸、深色里是 T10），等宽数据行带级别文字，可键盘滚动；级别是一枚小字牌（信息取 secondary-container、警告 / 错误取各自的容器色），警告与错误的行首另有一道色条，扫读时一眼能跳到它们；日志突发不逐行播报；前后台订阅、暂停、筛选、导出维持原行为。行内版式看日志框自己的宽度（`@container log`）：≥44rem 一行四列（时间 / 级别 / 来源 / 正文），窄时来源与正文各占一行。总览里的「最近日志」只有半栏宽，旧版按视口定列，桌面规则把正文挤成一条竖排窄列。
- **搭话 · 记忆**：记忆按群号存，标题显示群名（向 `/api/groups` 要名册，群号退到副标题）；读不到时仍是「群 123456」。
- **中西文混排**：`text-autospace: normal`，中文与西文、数字相接处自动留出细空隙，文案里不必手敲空格。
- **安全**：动态 HTML 经 `h\`\`` 模板转义，只有可信片段用 `raw()`；不要在页面代码中直接拼未经转义的 `innerHTML`。

## 无障碍与验证

目标为 WCAG 2.2 AA：普通文本 ≥4.5:1，大字与有意义的非文本边界 ≥3:1；不只靠颜色传意；键盘可达、焦点清楚且不被顶栏 / 底栏遮挡；不设置单字符快捷键；320px 回流、200% 放大与文字间距可用；口令可粘贴及自动填充。自动审计不是无障碍认证；VoiceOver / TalkBack 与实际设备安全区需人工验收。

```sh
python3 scripts/make-tokens.py --check
python3 scripts/make-icons.py --check
cargo test --locked console
python3 scripts/audit-contrast.py   # 对运行中的本机控制台只读检查
```

颜色与组件检查覆盖四种外观以及 320 / 390 / 800 / 1400px；测试还覆盖键盘、对话框、配置验证与日志突发。上线前必须运行隔离测试，并检查线上实际内嵌资源，不能只依据源码截图宣称通过。

## 聊天、内容与数据契约

- **信息卡版式**（手册、控制、智能体与模型列表共用 `render::web` 的文档模型与 `res/cards/reading.css`）：卡面统一 520 宽（成图 560，与智能回复卡同宽），手机全屏看时正文约 13dp，**内容多就让图变长，不让字变小**；一组条目用 M3E 分段列表（`md-seg`）收成一块——外端大圆角、组内小圆角、条间一道细缝，不再每条画一圈边。指令里照打的字用主色加粗，`<占位>` 与 `[可选]` 降一档；状态永远带文字，圆点另有实心 / 空心 / 带环三种形状；启用是常态，只给例外（已停用、待重启）挂标记。只剩一个成员的分组不单独立标题，并进「其他」，成员自己带上原本挂在标题上的那一项。
- help、ctl、oai（回复卡与两张列表）、ai_news 的信息卡出图成功后只发卡片图，不再补发等价文本；图片没出成（关掉出图或渲染失败）才退回文本。统计图与词云同此口径。长文本按适配器容量分段，资讯长内容沿用合并转发。图中来源保留完整 URL，OAI 卡片同时带来源与工具回执。`image_enabled=false` 仍可选择纯文本。
- 渲染不信任模型 HTML，原始标签作为文本转义。内置清单使用 Markdown，让图片与文本共用同一份内容。Markdown 卡的元素样式、分页与对比度检查见 [Markdown 转图](markdown.md)；代码着色只取 M3 角色色，前景与代码面的对比度由测试卡在 4.5:1 以上。
- 图表条长从零正比映射，名称与数值分开布局；多系列折线的编号同时出现在图例与数据点，不能仅凭颜色区分。
- 指令元数据以真实解析器为准，复制按钮只复制一个模板，按当前配置补词前缀；符号指令与智能体名称保持原样。尖括号表示需要替换的参数。
- 配置标签与说明来自配置参考（`config.example.toml` 的注释；表头前那段话是这一节的说明，注释里的示例配置不算说明）；有限选项由后端校验规则提供（`ctl::options`）。群号 / 账号列表用名单编辑器，其余标量列表用列表编辑器，对象列表或混合类型仍用多行 JSON，保留类型、引号与含逗号字符串。包含已隐藏凭据的列表不可把占位文字当真实值提交。
- 保存成功仅指本次提交的数据已持久化；保存期间的新编辑必须继续排队或保留为草稿。OAI 保存采用原子替换，失败回滚内存并报告错误。刷新、断点切换与保存其他表单不得丢失输入或焦点；离开未保存表单需确认。**「未保存」只认用户亲手输入过且与基线不同的值**（`beforeinput` 标记）：打开页面什么都没改、点开再点关的开关、浏览器 / 密码管理器自动填充、扩展写值、表单恢复都不算，正在保存的控件也不算。访问令牌框只提交亲手输入的内容，自动填进来的（只可能是控制台口令）会被清掉；要清除已设的令牌用「清除已设的令牌」开关，留空只表示不改动。离开确认点名是哪几处没保存，默认焦点在「继续编辑」；取消后历史原路退回（后退栈不留重复条目，手势返回照常）。
- 删除智能体、删除历史、清空历史需操作者在相同会话中于 60 秒内重发同一指令确认；目标数据变化时重新确认。
- 用户主动指令的失败给出结果、原因与下一步；自动监听的无结果不强制制造群聊提示。全局白名单与插件 channel 是独立规则，界面必须描述真实优先级。
- 表情画廊默认静态第一帧，原图需主动播放，可随时停止。静态卡片无交互动效要求；控制台继续尊重减少动态与强制颜色偏好。
- Apple HIG 仅用于平台体验。用户提供的图片、视频、网页截图与角色创作内容不视为框架自定义视觉组件。

## 依据与验收边界
